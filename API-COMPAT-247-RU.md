# API-аудит build 247 — Minecraft 1.21.1 / NeoForge 1.21.1

Сверка исходников, а не запуск игры. В JAR добавлен только `dev/settledlands/npc/BodilessProtection.class`, compile-only силуэты не включены. Аннотация `@EventBusSubscriber(modid="settledlands")` и четыре статических `@SubscribeEvent(priority=LOWEST)` регистрируются обычным механизмом NeoForge; порядок чужих LOWEST-обработчиков не гарантирован.

- [Player.java.patch](https://github.com/neoforged/NeoForge/blob/1.21.1/patches/net/minecraft/world/entity/player/Player.java.patch) вызывает `CommonHooks.onPlayerAttackTarget` в начале `Player.attack(Entity)`. [AttackEntityEvent](https://github.com/neoforged/NeoForge/blob/1.21.1/src/main/java/net/neoforged/neoforge/event/entity/player/AttackEntityEvent.java) отменяемый; `PlayerEvent.getEntity()` возвращает `Player`, `getTarget()` — `Entity`.
- [LivingEntity.java.patch](https://github.com/neoforged/NeoForge/blob/1.21.1/patches/net/minecraft/world/entity/LivingEntity.java.patch) вызывает `onEntityIncomingDamage` перед обработкой, отмена прерывает `hurt`. [LivingIncomingDamageEvent](https://github.com/neoforged/NeoForge/blob/1.21.1/src/main/java/net/neoforged/neoforge/event/entity/living/LivingIncomingDamageEvent.java) отменяемый, `getSource(): DamageSource`. [DamageSource](https://github.com/Yeet-Masta/MCP-1.21/blob/main/src/main/java/net/minecraft/world/damagesource/DamageSource.java) различает `getEntity()` (причина) и `getDirectEntity()` (непосредственный источник). В стрелах `getEntity` обычно владелец, а direct — снаряд. `Projectile.getOwner(): Entity`, `AreaEffectCloud.getOwner(): LivingEntity`.
- [MobEffectEvent.Applicable](https://github.com/neoforged/NeoForge/blob/1.21.1/src/main/java/net/neoforged/neoforge/event/entity/living/MobEffectEvent.java) содержит `getEntity()`, `getEffectInstance()`, `getEffectSource()` и `setResult(Applicable.Result.DO_NOT_APPLY)`. `LivingEntity.addEffect/forceAddEffect` через `CommonHooks.canMobEffectBeApplied` генерируют его. [ThrownPotion](https://github.com/Yeet-Masta/MCP-1.21/blob/main/src/main/java/net/minecraft/world/entity/projectile/ThrownPotion.java) при обычном броске передаёт владельца, [AreaEffectCloud](https://github.com/Yeet-Masta/MCP-1.21/blob/main/src/main/java/net/minecraft/world/entity/AreaEffectCloud.java) — себя. `MobEffectInstance.is(Holder<MobEffect>)`; `MobEffects.POISON`, `WITHER`, `HUNGER` — holders. Позднее яд/иссушение вызывают hurt без причинной сущности, поэтому блокируется их применение, если источник установлен.
- NeoForge [MilkBucketItem.java.patch](https://github.com/neoforged/NeoForge/blob/1.21.1/patches/net/minecraft/world/item/MilkBucketItem.java.patch): молоко вызывает `removeEffectsCuredBy(EffectCures.MILK)`. [LivingEntity.java.patch](https://github.com/neoforged/NeoForge/blob/1.21.1/patches/net/minecraft/world/entity/LivingEntity.java.patch) проходит эффекты и для каждого cure отправляет отменяемый `MobEffectEvent.Remove`. Отменяется только комбинация `getCure()==MILK` и `getEffect().is(PossessionSystem.BODILESS_ID)`. Это работает и для старого сохранённого экземпляра с молоком в cures; молоко не подменяется, прочие эффекты удаляются штатно. `removeEffect` вызывает то же событие с `cure=null`, поэтому вселение и явное снятие не блокируются. Тотем имеет другой cure.
- [Holder](https://github.com/Yeet-Masta/MCP-1.21/blob/main/src/main/java/net/minecraft/core/Holder.java) действительно объявляет `is(ResourceLocation)`. `Level.dimension(): ResourceKey<Level>` сравнивается с `Level.OVERWORLD`; проверяется измерение цели. [Bus ICancellableEvent](https://github.com/neoforged/Bus/blob/main/src/main/java/net/neoforged/bus/api/ICancellableEvent.java) содержит default `setCanceled(boolean)`; JVM-стенд использует наследование с таким интерфейсом.

Ограничения: огонь/лава/падения и другие действия, где Minecraft больше не хранит виновника, не могут быть уверенно отфильтрованы; сторонний код может использовать другие события/порядок. Диспетчер в тесте синтетический, фактическая авторегистрация, мир, транспорт, применение mixin и все перечисленные дескрипторы в настоящем runtime требуют игровой проверки.
