# Build 257 — заметки по совместимости и точному diff

## База и изменённые записи

Новая версия строится только от `settledlands-0.8.0-build256-npc-fp-corpse.jar` (SHA-256 `024937159ceb6f7173591dacf30d0c46b2fcc5233e8b495e4918d56b715c2021`). В JAR изменены ровно четыре записи:

- `dev/settledlands/npc/GuideNpc.class`
- `dev/settledlands/npc/NpcAutoAiEngine255.class`
- `META-INF/neoforge.mods.toml`
- `settledlands-patch-info.txt`

Остальные 419 записей совпадают с build 256 байт-в-байт. В `GuideNpc` затронуты только `customServerAiStep()V` и `walkingNavigationSpeed(Z)D`. Первый без изменения ветвлений вызывает синхронизацию Stats в начале серверного AI-тика, а прежний вызов `aiMode()` в единственной ветке заменён на равнодлинный `NpcAutoAiEngine255.legacyAiMode(GuideNpc)I`. Поэтому при включённой автоатаке старый Ivy combat tick не может перехватить тик автономного ИИ; при выключенной настройке возвращается прежний `aiMode`. Вторая функция компенсирует обратное масштабирование скорости навигации и задаёт коэффициент 0.5 только в спокойном состоянии. В бою коэффициент остаётся 1.0.

Новый движок — серверный, без ссылок на клиентские классы. Он читает три параметра через существующую `NpcStatsGraph` и `NpcAutoAi255` логику:

- здоровье: `MAX_HEALTH` получает постоянную модификацию `2 × (health − 10)` HP. Понижение максимума сразу ограничивает текущее здоровье новым максимумом;
- урон: `ATTACK_DAMAGE` получает множитель `damage / 10`;
- скорость: `MOVEMENT_SPEED` получает множитель `speed / 10`.

Модификаторы принадлежат `settledlands:npc_stats_health`, `settledlands:npc_stats_damage`, `settledlands:npc_stats_speed` и не заменяют базовые значения или чужие атрибутные модификаторы. Синхронизация кэшируется по профилю/графу и значениям ноды, с периодической сверкой при том же профиле. Для NPC без ноды используются значения по умолчанию прежнего Stats API. Трупы и триггерные NPC исключены из нового пути.

## Сохранённое поведение и пределы

Авто-атака остаётся управляемой тем же флагом в настройках NPC и редакторе графа, что и build 255. Новый приоритет применяется только к активным NPC, когда их флаг автоатаки включён. Отключённая автоатака, автономная прогулка, боевые комбо/увороты Иви, путь возврата домой, поводок, диалог, скриптовое движение и исключения `GuideCorpseNpc`/`GuideTriggerNpc` сохранены.

Мирное ожидание в точке составляет случайные 400–900 тиков (20–45 секунд). Оно не меняет радиус прогулки, поиск безопасной точки и базовый лимит возвращения.

Проверки Java 21 исполняют классы на синтетических Minecraft/NeoForge API; это не подтверждает работу в конкретной версии игры, конкретной конфигурации сторонних модов, визуальную скорость анимации или применение Mixin в полноценной загрузке. См. `CHECKLIST-TEST-BUILD257-RU.md`.
