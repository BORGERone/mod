# Build268 source backup / повторная сборка

Исходный ZIP включает точную базу Build262, кандидат Build268, sources, `tools/api268` с исправленными Mixin annotation retention stubs, сборщик, gates, README и игровой checklist. Пользовательские логи в архив не включаются.

Повторить из корня архива:

```bash
python3 tools/patch_profession_skin_probe268.py --java <путь-к-Java-21>
python3 tests/gate_build268.py --java <путь-к-Java-21>
python3 tests/gate_backup268.py --java <путь-к-Java-21>
```

Первый gate сверяет точную пересборку и classfile metadata; backup gate проверяет manifest и запускает полный Build268 gate из чистой распаковки. Успех gate — не тест Minecraft/NeoForge и не визуальное подтверждение.
