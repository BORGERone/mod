Проверка скачанного build 242 (Windows PowerShell)

Сохраните jar по ссылке как файл с расширением .jar и проверьте:

$filename = 'settledlands-0.8.0-build242-body-required.jar'
$url = 'https://raw.githubusercontent.com/BORGERone/mod/arena/24676dbe-mod/settledlands-0.8.0-build242-body-required.jar'
Invoke-WebRequest -Uri $url -OutFile $filename
(Get-Item $filename).Length
(Get-FileHash $filename -Algorithm SHA256).Hash

Должно получиться:
Length = 1551583
SHA256 = 375e8faed7ea19e7bc1c343a043f833f82112a10b0ff17c1f6982bc18c2afe6d

Альтернатива для проверки хеша:
certutil -hashfile settledlands-0.8.0-build242-body-required.jar SHA256

Если загрузка не удалась, резервная ссылка:
https://github.com/BORGERone/mod/raw/arena/24676dbe-mod/settledlands-0.8.0-build242-body-required.jar

При несовпадении размера/хеша удалите файл и скачайте заново; не запускайте обрезанный jar. GitHub Contents API для файлов больше 1 MiB не отдаёт base64.
