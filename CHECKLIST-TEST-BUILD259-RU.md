# Игровая проверка build 259

Перед обновлением сделайте копию мира. Удалите из `mods` все старые JAR SettledLands, особенно build 258, и оставьте только `settledlands-0.8.0-build259-npc-combo-tuning.jar`.

- [ ] Мир запускается на целевой версии Minecraft/NeoForge, GuideNpc загружаются без серверного вылета на первом AI-тике (проверка прежнего ABI hotfix).
- [ ] Включите автоатаку против hostile-моба и понаблюдайте, как NPC сближается: корпус должен быть направлен по ходу движения, а не идти боком, постоянно повернувшись к цели. Поворот головы к цели не обязателен.
- [ ] Проверьте обычную спокойную прогулку NPC: темп должен быть немного выше build 258, но не резко ускоренным. Значение Speed в ноде характеристик по-прежнему влияет на скорость.
- [ ] Дождитесь ближнего боя: NPC должен выполнять серию Ivy-анимаций (jab-cross либо jab-jab-hook), а серия — наносить несколько ударов. Атака с рывком также должна переходить в многосоставную комбинацию.
- [ ] Проверьте прежние функции: автоатака только hostile-мобов, урон/скорость/здоровье из Stats-ноды, самостоятельная прогулка и возврат домой после погони.
- [ ] Убедитесь, что труп/гроб, поводок, возврат предметов и сохранение мира работают как раньше.

Достаточно сообщить кратко, что работает, или прислать свежий `logs/latest.log` и crash report, если возникнет ошибка. Видео не нужно. JVM gate не заменяет реальный запуск Minecraft/NeoForge.
