# Игровая проверка build 260

Сначала сделайте копию мира. Удалите предыдущие JAR SettledLands, включая build 259, и оставьте только build 260.

- [ ] Обычный NPC больше не издаёт звуки скелета при ожидании, получении урона и смерти; он использует звуковой набор жителя.
- [ ] При включённом «смотрит на игрока» NPC может следить за игроком головой, но при ходьбе корпус смотрит по направлению движения и NPC не идёт боком, повернувшись к игроку.
- [ ] При выключенном тумблере NPC также идёт корпусом вперёд по маршруту/к цели, а не боком.
- [ ] Начните диалог при выключенном тумблере: NPC должен смотреть на игрока во время разговора.
- [ ] Проверьте изменения при обоих состояниях тумблера, включая автоатаку/обычную прогулку, сохранение остальных анимаций и предметов в руках.
- [ ] Убедитесь, что Build 259 функции сохранились: Ivy-комбо с follow-up ударом, небольшое ускорение спокойной ходьбы, Auto-AI hostile targets, Stats, блуждание и возврат домой.
- [ ] Убедитесь, что мир загружается и NPC тикают без ABI/crash, и что прежние труп/гроб, поводок, возврат предметов и сохранение мира работают.

Для обратной связи достаточно коротко описать, какие пункты прошли; если ошибка — приложить свежие `logs/latest.log` и crash report. Видео не нужно. JVM gate не является запуском Minecraft/NeoForge.
