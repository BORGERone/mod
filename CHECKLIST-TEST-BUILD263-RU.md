# Игровая проверка SettledLands Build 263

Minecraft/NeoForge из песочницы не запускались. Этот чеклист нужен для первой
проверки в настоящем мире. Видео не просить; при проблеме достаточно текста,
свежего `latest.log` и, если есть, crash report.

## Перед запуском

1. Сделать копию мира и списка модов.
2. Удалить старые JAR SettledLands из `mods` и оставить только
   `settledlands-0.8.0-build263-cutscene-fade.jar`. Source ZIP в `mods` не класть.
3. Сверить SHA-256 скачанного JAR по `SHA256SUMS-build263.txt`.

## Проверка редактора и сохранения

1. Открыть редактор графа, выбрать существующую или создать CUTSCENE-ноду.
2. Убедиться, что в инспекторе появились две отдельные кнопки:
   «Затемнить при старте» и «Проявить после затемнения».
3. Включить по одной галке, сохранить граф/профиль, закрыть и открыть редактор снова;
   проверить, что каждое состояние сохранилось независимо.
4. Проверить выключение тумблера, undo/redo и дублирование ноды. У ноды анимации
   не должно меняться «Повторять», у ноды перемещения — «Сопровождать».

## Проверка переходов

1. В копии мира использовать сцену с достаточно длинной камерой и подключить её к
   действию графа, которое запускает катсцену.
2. Обе галки выключены: камера запускается как раньше, без чёрного слоя.
3. Только «Затемнить при старте»: изображение плавно темнеет около 0,5 секунды;
   камера начинает работу лишь после полного чёрного, после чего слой открывается
   сразу (без невыбранного fade-in).
4. Только «Проявить после затемнения»: экран ждёт сигнал старта камеры на чёрном и
   затем плавно проявляется около 0,5 секунды.
5. Обе галки включены: движение/изображение камеры не должно начинаться до полного
   затемнения; на чёрном камера запускается, затем идёт fade-in около 0,5 секунды.
   Проверить отсутствие кадра сцены между началом затемнения и полным чёрным.
6. Соединить несколько CUTSCENE-нод подряд с разными настройками; проверить, что
   каждая следующая сцена применяет именно свои параметры, включая переход через
   пустую CUTSCENE-ноду без имени сцены.
7. Прервать катсцену штатной остановкой, затем запустить другую без fade. Экран не
   должен навсегда оставаться чёрным и не должен продолжать старый переход. Если
   сигнал камеры не приходит, overlay должен восстановить изображение, а не зависнуть.

## Регрессии и сообщение о проблеме

Проверить, что камера/диалог заканчиваются штатно, а ранее существовавшие настройки
анимации и перемещения, сохранение графа и другие механики работают как прежде.
Если есть сбой, сообщить версию Minecraft/NeoForge, шаги и приблизительное время;
приложить свежий `latest.log` этого запуска и crash report при наличии. Видео не нужно.
