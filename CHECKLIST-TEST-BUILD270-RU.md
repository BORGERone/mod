# Проверка Build270 Pursuit hotfix на копии мира

## Перед запуском
- [ ] Сохранена копия мира и резервная копия `mods`.
- [ ] Build269 удалён из `mods`; установлен только Build270 (не держать оба JAR).
- [ ] Среда: Minecraft 1.21.1 + NeoForge 21.1.253, совместимый набор зависимостей.

## Старт клиента — главное для hotfix
- [ ] Игра достигает главного меню без `InvalidMixinException` / `Screen is not an interface`.
- [ ] Мир загружается.
- [ ] Граф NPC открывается, правая панель инспектора отображается.
- [ ] Контрол выбора pursuit-команды появляется у Trigger-ноды.

Если игра падает, приложить свежий `latest.log`; видео и SHA JAR не нужны.

## Функциональность (только если запуск успешен)
- [ ] Trigger-команда начинает преследовать NPC по точному значению существующего поля «Идентификатор NPC».
- [ ] Trigger-команда начинает преследовать игрока по нику.
- [ ] Несколько преследователей распределяются рядами, не собираются в одну точку.
- [ ] Отдельный Trigger прекращает преследование исполнителя.
- [ ] После сохранения/перезахода состояние ведёт себя ожидаемо.

Отметьте выполненные/не выполненные пункты. Пока пользовательский запуск не подтверждён, Build270 считается кандидатом, а не игрово-проверенным выпуском.
