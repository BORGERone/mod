# Проверка Build271 на копии мира

## Перед стартом
- [ ] Сделана копия мира и резервная копия папки `mods`.
- [ ] Build269 и Build270 удалены; установлен только Build271.
- [ ] Minecraft 1.21.1 / NeoForge 21.1.253 и зависимости совместимы.

## Старт и создание нод
- [ ] Клиент запускается без crash.
- [ ] Открывается редактор графа NPC.
- [ ] В меню создания видны отдельные «Преследование — начать: NPC», «…начать: игрок», «…прекратить».
- [ ] Каждая создаёт отдельную подписанную ноду; создание стандартной Trigger-ноды больше не падает.
- [ ] Ноды можно соединить в графе и сохранить.

## Поведение
- [ ] NPC-цель использует точный существующий «Идентификатор NPC».
- [ ] Игрок-цель использует ник.
- [ ] Несколько NPC строятся рядами, не сливаются в одну точку.
- [ ] Отдельная нода stop прекращает погоню.
- [ ] Сохранение/перезагрузка Guide NPC больше не вызывает NBT error; pursuit ведёт себя ожидаемо после reload.

Если что-то не проходит, приложите свежий `latest.log` и назовите номер пункта. Видео и SHA установленного JAR не нужны. До теста считать Build271 кандидатом.
