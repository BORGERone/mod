SettledLands 0.8.0 — сборка 246 «Характеристики NPC»
Minecraft 1.21 / NeoForge; основа — проверенная сборка 245.

ИЗМЕНЕНИЯ
• Бестелесный получает 50% обычной гравитации; стандартные мобы не выбирают
  его целью и забывают существующую цель. Другим игрокам он виден.
• В основном графе NPC автоматически появляется большая нода «Характеристики»:
  «Здоровье», «Урон», «Скорость», отдельные кнопки −/+; начальное значение 10.
  Диапазон интерфейса 1–100; параметры сохраняются индивидуально для каждого NPC.
• Здоровье 10 = 20 HP = 10 значков сердец, 11 = 22 HP = 11 значков;
  каждый пункт изменяет максимум на 2 HP. Урон и скорость масштабируют итоговое
  значение: 11 = 110%, 9 = 90%, с учётом экипировки и других бонусов.
• ПКМ бестелесным по живому NPC открывает экран характеристик, а не диалог;
  «Вселиться» проверяется сервером заново, включая локальный культ NPC ≥ 1,
  расстояние, срок, прежние значения и одноразовый ключ. Инструменты редактирования
  и взаимодействия с телом сохраняются.
• Сохранены износ −4/−8/−16 максимального HP за 1/2/3 успешных платных
  возврата, обычный дроп по правилам мира при четвёртой смерти без тела,
  самостоятельный выход без прибавки износа и сброс износа для нового NPC.
  Алтарь не использует очередь: рядом нужно собственное тело/гроб, цена —
  9 изумрудов за каждого. Обычная смерть не создаёт тело. Вещи и поводок
  по правилам сборки 244; трупы/гробы не являются нежитью и неуязвимы.

УСТАНОВКА
Сделайте резервную копию мира. Замените старый JAR SettledLands в папке mods
этим JAR, не оставляйте обе версии одновременно. Для сервера и игроков должна
использоваться одна версия мода. Следуйте CHECKLIST-TEST-BUILD246-RU.md.

ГРАНИЦЫ ПРОВЕРКИ
Автоматические тесты запускают настоящий Java 21 JVM с синтетическими моделями
API Minecraft/NeoForge, а не саму игру. Minecraft, NeoForge, реальное применение
mixin, сохранение мира, физика и сетевой обмен в игре не проверялись. Мобы с
нестандартным AI сторонних модов могут обходить стандартный выбор цели; порядок
обработчиков урона других модов также не гарантирован. Старую причину отказа
при выполненном «культ=1» установить не удалось; диагностический probe только
читает данные. Унаследованная оговорка 245: после неудачного штатного спавна
fallback может создать неподтверждённое тело; UUID не угадывается.

СБОРКА И АВТОПРОВЕРКА
В архиве с AI-GUIDE и test-inputs из корня распаковки (нужна Java 21):
  python3 tools/patch_npc_stats246.py --base settledlands-0.8.0-build245-body-wear.jar --out /tmp/rebuilt246.jar --java /путь/к/java
  python3 tests/gate_build246.py --inputs test-inputs --base245 settledlands-0.8.0-build245-body-wear.jar --java /путь/к/java --jar settledlands-0.8.0-build246-npc-characteristics.jar
Компилятор ECJ и его лицензия находятся в tools/vendor; генерируемые API-силуэты
используются только при компиляции и не включаются в мод.
