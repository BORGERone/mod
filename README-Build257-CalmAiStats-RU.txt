ОТОЗВАНО: build 257 содержит ABI-ошибку и вызывает вылет `NoSuchMethodError` на первом тике NPC в Minecraft 1.21.1. Не устанавливать; использовать build 258 hotfix.

SettledLands 0.8.0 — build 257 (историческая сборка)
Мирная скорость НПС, автоатака и характеристики

Что изменено относительно build 256

• Спокойная ходьба NPC вдвое медленнее. Во время активной рукопашной схватки сохраняется прежний темп build 255. Скорость по-прежнему индивидуально масштабируется характеристикой «Скорость» именно этого NPC.
• Ожидание в выбранной точке прогулки увеличено до 400–900 игровых тиков (20–45 секунд). Маршруты, домашняя область, возврат после ухода/боя, поводок и приоритет скриптового движения сохранены.
• Исправлен конфликт включённой автоатаки с прежним боевым тиком Ivy: когда включена автоатака враждебных мобов, старый тик больше не перехватывает ход ИИ. Враждебная цель выбирается, атакуется ближним боем; фаерболы не добавлены. Когда автоатака выключена, прежний путь сохранён.
• Индивидуальная нода «Характеристики» синхронизируется с атрибутами конкретного NPC: здоровье, урон и скорость. Для здоровья изменяется максимальный запас и текущее здоровье не остаётся выше нового максимума. Значение 10 сохраняет базовый уровень; 20 даёт 40 HP, вдвое больший урон и скорость; 5 — 10 HP, половину урона и скорости. При обычной спокойной ходьбе применяется дополнительная половина, но в бою этот дополнительный множитель не применяется.
• Функции, настройки и UI из build 255, а также механики 237–256 сохранены.

Проверки

Полный автоматический build-257 gate: `GATE-RESULT-257.txt`. Включает побайтово воспроизводимую сборку от точной базы build 256, структурные/JVM проверки, предыдущие записанные полные gate 256, наследуемый сценарий Auto-AI 255 и новые Java 21 сценарии. Четыре verifier-valid отрицательных мутанта намеренно отключают синхронизацию характеристик, половинный спокойный темп, приоритет автоатаки и длинную остановку; все четыре обнаружены тестами.

Это не запуск Minecraft/NeoForge и не игровая/визуальная проверка. Перед использованием сделайте копию мира и проверьте чеклист `CHECKLIST-TEST-BUILD257-RU.md`. В `mods` оставьте только один JAR SettledLands.
