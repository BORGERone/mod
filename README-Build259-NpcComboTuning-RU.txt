SettledLands 0.8.0 — build 259
NPC: направление корпуса, скорость ходьбы и серии ударов

Build 259 продолжает build 258 и сохраняет исправление JVM ABI для Minecraft 1.21.1. Во время навигации к противнику NPC больше не поворачивает корпус к цели отдельным вызовом; модель должна идти по направлению движения. Активный поворот головы к цели во время ходьбы не используется. Спокойная скорость NPC повышена на 10% (коэффициент 0,50 → 0,55); боевой темп и влияние Stats-ноды сохранены.

Обычные атаки теперь выбираются из двух многосоставных анимаций Иви: jab-cross и jab-jab-hook, с несколькими моментами попадания. Дальний рывок также начинает одну из этих серий. Автоатака hostile-мобов, Stats здоровья/урона/скорости, прогулка/возврат домой и прежние melee-анимации сохранены.

Сборка детерминированно основана на build 258. Изменены ровно три JAR-записи; boolean ABI hotfix не регрессировал. Основной и независимый JVM gate прошли, включая реальное выполнение второго удара в серии, четыре отрицательных мутанта и проверку воспроизводимости. Полный Minecraft/NeoForge запуск не выполнялся.

До установки удалите предыдущие JAR SettledLands, сначала сделайте копию мира и проверьте пункты `CHECKLIST-TEST-BUILD259-RU.md`. Видео не требуется.
