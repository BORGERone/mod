SettledLands 0.8.0 — build 260
Звуки NPC, поворот корпуса при ходьбе и взгляд в диалоге

Исправлены три замечания пользователя:
1. Обычные GuideNpc использовали скелетные ambient/hurt/death звуки. Теперь это звуки жителя.
2. При включённом «смотрит на игрока» обычный LookControl разворачивал корпус за игроком даже во время ходьбы. Теперь тумблер задаёт только поворот головы, а отрисовываемый корпус выравнивается по вектору реального перемещения. Это применяется и при включённом, и при выключенном тумблере.
3. При выключенном тумблере look-at всё равно включается на время диалога; рендер не блокирует поворот головы во время разговора.

Сборка основана на build 259. Сохранены Ivy multi-hit-комбо, повышенная на 10% спокойная скорость, Stats-driven HP/damage/speed, Auto-AI, блуждание/возврат домой и boolean ABI hotfix build 258. Основной и независимый JVM gate прошли, включая проверки диалогового поворота головы и пяти отрицательных мутантов. Полный Minecraft/NeoForge запуск не выполнялся.

Удалите старые JAR SettledLands, установите только build 260 и проверьте на копии мира по `CHECKLIST-TEST-BUILD260-RU.md`. Видео не требуется.
