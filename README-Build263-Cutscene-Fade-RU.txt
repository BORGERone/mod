SettledLands Build 263 — плавный переход катсцен через чёрный экран

База: точный Build 262
settledlands-0.8.0-build262-smooth-npc-turning.jar
SHA-256: 21fc8fa7c861c3652f020ce9bb10bac133ac253675084982e65f16cc734f2531

В инспекторе каждой CUTSCENE-ноды есть два независимых тумблера:
• «Затемнить при старте» — плавно закрыть изображение чёрным до полной темноты;
• «Проявить после затемнения» — открыть изображение плавно после фактического старта камеры.

Строгий порядок: затемнение заканчивается на полном чёрном; только затем клиент
запускает камеру и передаёт сигнал начала воспроизведения; при включённом проявлении
после этого начинается fade-in. Обе галки дают переход через полный чёрный экран.
Каждая фаза длится 500 мс. При включённом только затемнении экран мгновенно
открывается при старте камеры (без незаказанного fade-in); при включённом только
проявлении сцена ждёт сигнала камеры на чёрном и затем проявляется. После playback
слой очищается; потерянный сигнал старта не оставляет экран чёрным дольше 10 секунд.
При выключенных обеих галках поведение прежнее.

Настройки сохраняются в графе, переживают копирование/undo и применяются также
к последовательно связанным катсценам. Флаги хранятся раздельно через Mixin-added
поля ноды; `animLoop` и `moveEscort` не используются. Общий graph editor, graph NBT
save/load, copy и chained playback подключены отдельными mixin hooks.

Объём diff относительно Build 262: 7 существующих ZIP-записей изменены и 11
новых class-записей добавлены; остальные файлы JAR побайтно сохранены. Список,
размеры и SHA-256 — в `GATE-RESULT-263.txt` и `SHA256SUMS-build263.txt`.
