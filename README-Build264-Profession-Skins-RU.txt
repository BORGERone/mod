SettledLands Build 264 — профессии и скины NPC

Основа: точный settledlands-0.8.0-build262-smooth-npc-turning.jar.
Build 263 с CUTSCENE fade не является базой и в Build 264 не переносился.
Переходы CUTSCENE не добавлялись и Build 263 не изменялся.

Что добавлено
- В узел «Характеристики» графа NPC под кнопкой «Рандомизировать» добавлен круговой селектор профессии. Названия короткие: «Рыбак», «Пастух», «Страж», «Командир», «Крестоносец», «Фермер», «Кузнец», «Торговец», «Селянин», «Маг», «Целитель», «Шахтёр», «Лесоруб», «Охотник», «Трактирщик», «Волшебник»; доступен вариант «Без профессии».
- Ниже находятся два отдельных тумблера с точными подписями «муж» и «яп».
- Профессия и оба флага сохраняются в существующих полях узла графа. В сборочном шлюзе проверяются копирование узла и наличие NBT-ключей DamageFilter/MinDamage в сериализации Build 262.
- Для стандартной модели Ivy выбранная профессия задаёт embedded-текстуру. Поддерживаются обычные NPC и копия модели при вселении; трупы и trigger-NPC остаются на прежнем пути.
- Если у профессии нет отдельной текстуры для сочетания флагов, используется доступный вариант; если подходящей текстуры нет — исходная Ivy.

Модель
- Новая модель: assets/settledlands/dragon_default/ivy_oleander_professions.bbmodel.
- Формат Blockbench Bedrock, элементы геометрии и кости сохранены, все PNG встроены как data:image/png;base64.
- Сопоставление имён проверяется со всеми строками в Java-маппинге. Шлюз декодирует PNG и запускает фактический helper из итогового JAR для всех 64 сочетаний (16 профессий × 2 флага × 2 пола/региона), сверяя SHA-256 выбранной embedded-текстуры с исходной.
- Полный исходный набор текстур остаётся во встроенной Blockbench-модели. Для runtime-варианта helper оставляет в копии только первый embedded source (именно его использует `BbModelParser.loadTexture`), заменяя его выбранной PNG; лишние текстуры из runtime-копии удаляются.
- Динамические варианты создаются в папке Settled Lands models; тест выполняет то же создание на временном каталоге. Визуально в игре модель не проверялась.
