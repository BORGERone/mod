SettledLands Build 265 — выпадающий список профессий и применение скина

Build 265 создан от точного Build 262. CUTSCENE fade из Build 263 не переносился.

Исправления после пользовательской проверки Build 264
- Вместо стрелочного переключателя профессий теперь используется настоящий выпадающий список с короткими названиями. В списке 17 вариантов, включая «Без профессии»; длинный список прокручивается.
- Выбранная профессия теперь применяет текстуру модели профессий даже если у профиля NPC до этого был другой путь модели. «Без профессии» оставляет обычную текстуру профиля.
- Переключатели «муж» и «яп» сохранены; профессия и флаги хранятся в существующих полях узла. Применение профиля и синхронизация DATA_TEXTURE происходят при сохранении графа на сервер.
- Положение и оформление выпадающего меню используют штатный NpcUi.NpcDropdown, уже встроенный в графовый экран.

Модель
- В JAR встроена `assets/settledlands/dragon_default/ivy_oleander_professions.bbmodel` с embedded PNG.
- Client helper выбирает текстуру, создаёт variant `.bbmodel` с сохранёнными геометрией и анимациями, а loader получает соответствующий путь.

Проверки
`python3 tests/gate_build265.py --java /путь/к/java21` и `python3 tests/gate_backup265.py --java /путь/к/java21` должны завершиться PASS. Проверены детерминированная сборка, JAR/diff, ссылки dropdown API и skin mapping, сериализуемые поля, схема/PNG модели и точное соответствие embedded texture во всех 64 сочетаниях.

Minecraft/NeoForge не запускались. Визуальная работа dropdown, применение скина в мире и поведение при сохранении требуют пользовательской проверки на копии мира по `CHECKLIST-TEST-BUILD265-RU.md`. Никаких утверждений о визуальном тесте в игре нет.
