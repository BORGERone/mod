Build 269 добавляет преследование NPC и игроков командами графа. Основа — подтверждённый пользователем Build 268; его исправление профессии/скина сохранено. CUTSCENE fade Build 263 в эту сборку не переносился.

Как настроить граф
1. Откройте граф NPC и добавьте отдельный узел «Триггер» для начала.
2. В инспекторе выберите «Команды преследования» → «Начать: NPC по идентификатору» либо «Начать: игрок по нику».
3. В поле «Команда триггера» после автоматически вставленного префикса допишите точное значение из поля NPC «Идентификатор NPC» либо точный ник игрока.
4. Добавьте отдельный узел «Триггер» для остановки и выберите «Прекратить преследование».
5. Соедините эти узлы с событиями/ветками графа, которые должны запускать начало и остановку.

Каждый NPC, получивший команду старта на одну цель, рассчитывает позицию по UUID: три места в первом ряду примерно в 1,4–2 блоках от цели, следующие ряды — ещё через 1,5 блока. Позиции поворачиваются вслед за направлением цели. Это распределяет NPC по рядам, а не в одну точку.

Если цель не загружена, находится вне текущего измерения или игрок не в сети, преследование остаётся активным и ждёт появления доступной цели. Режим сохраняется в данных NPC. Разные цели формируют независимые группы. Остановка команды действует на конкретного NPC, выполнившего узел.
