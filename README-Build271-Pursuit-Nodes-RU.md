SettledLands 0.8.0 — Build271 «Отдельные ноды преследования»

Build269 и Build270 отозваны. Build270 падал при создании Trigger-ноды из-за AbstractMethodError в Screen invoker и не сохранял Guide NPC из-за NoSuchMethodError на CompoundTag.remove.

В контекстном меню создания graph node теперь есть три отдельные команды:
- «Преследование — начать: NPC» — создаёт ноду старта; в поле действия укажите точное значение существующего «Идентификатора NPC».
- «Преследование — начать: игрок» — создаёт отдельную ноду старта; в поле укажите ник игрока.
- «Преследование — прекратить» — отдельная нода остановки.

Ноды различимы по заголовку на графе, соединяются как обычные graph action nodes и сохраняют отдельные start/stop действия. Внутренне используются обычные Trigger node action strings, чтобы сохранить совместимость сериализации графа и исполнения действий.

Проверить на копии мира, по пунктам `CHECKLIST-TEST-BUILD271-RU.md`. Локальные deterministic/source gates прошли, но Minecraft/NeoForge в этой среде не запускались; запуск, графовый UI и реальное сохранение NPC требуют пользовательской проверки.
