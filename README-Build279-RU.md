# SettledLands 0.8.0 — Build 279 «Дистанция преследования»

Три замечания к 278 и что с ними сделано.

## 1. «NPC подходит вплотную»

Контроллер преследования (`NpcPursuit269`) останавливался на 1.25 блока **до
точки строя**, а сама точка стояла в 1.4 блока **перед** целью — то есть NPC
шёл к точке, которая лежит по ту сторону игрока, и останавливался где попало, в
том числе в теле игрока. Кроме того, остановка вызывала только
`navigation.stop()`: move control и остаточная горизонтальная скорость
оставались, поэтому тело ещё несколько тиков «доезжало» до игрока между
перестроениями пути.

Сделано:

* дистанция считается **до самой цели** и проверяется каждый тик, а не только
  на 10-тиковом перестроении;
* остановка делает то же, что `NpcEscort#stopMotion`: гасит навигацию, сбрасывает
  wanted position в move control, обнуляет `xxa/yya/zza` и горизонтальную
  скорость;
* преследователь идёт к точке на кольце дистанции **по своему направлению** от
  цели, а не к точке строя перед целью. Дойти до точки перед целью можно было
  только сквозь игрока — теперь этого пути нет;
* после остановки NPC снова идёт, только когда цель отошла на дистанцию +0.75
  блока (гистерезис, чтобы не дёргался).

## 2. «Догоняет, если игрок убежал»

Взят тот же механизм, что у ноды сопровождения (`EscortRules`):

* выше настроенной дистанции (по умолчанию 8 блоков) включается режим догона:
  скорость `GuideNpc#walkingNavigationSpeed(true)`, то есть
  `EscortRules.CATCH_UP_AI_SPEED` вместо `WALK_AI_SPEED`;
* путь перестраивается каждые 4 тика вместо 10;
* выход из догона — на `CATCH_UP_END_DISTANCE_SQ` (`9.0`, 3 блока), как в
  сопровождении.

## 3. «Настройки, насколько близко подходит»

У ноды преследования появились две строки в собственном инспекторе:

* **Дистанция:** 1.0 … 8.0 блока, по умолчанию **1.6** (просили 1–2);
* **Догонять с:** 2.0 … 48.0 блоков, по умолчанию **8.0**.

Обе — штатные поля ввода экрана (`doubleBox`: настоящий `EditBox`, фильтр
`[0-9]*\.?[0-9]*`, значение проверяется по диапазону), не рисование в канвасе.
Те же числа печатаются на карточке ноды строкой «Дистанция: 1.6  Догонять с: 8.0».

Хранение — в самом действии ноды, после разделителя `|`, который не может
встретиться ни в идентификаторе NPC, ни в нике игрока:

```
trigger:pursuit:start:npc:<цель>|<дистанция>|<догон>
trigger:pursuit:start:player:<ник>|<дистанция>|<догон>
```

Действия сохраняются вместе с графом, новых полей у ноды нет. Действия,
созданные 278 и раньше, читаются как есть и получают значения по умолчанию.
Настройки также попадают в NBT NPC (`PursuitKeep279`, `PursuitCatchUp279`),
поэтому переживают перезагрузку мира.

## Как собрано

Контроллер собран из настоящего исходника Build 271
(`reference/patch-src-build246-271/src/build271/dev/settledlands/npc/NpcPursuit269.java`),
а не переписан по байткоду: его перекомпиляция **без единой правки** даёт
байткод, совпадающий с классом из 278 по `max_stack/max_locals/code_len` во всех
17 методах. Правки внесены в этот исходник.

```
tools/vendor/ecj-3.46.100.jar -21 -g -nowarn \
  -cp build279-src/api:build279-src/api2:settledlands-0.8.0-build278-pursuit-card.jar \
  -d build279-src/out build279-src/src/...

python3 tools/patch_build279.py settledlands-0.8.0-build278-pursuit-card.jar
```

`build279-src/api2` — серверные заглушки Minecraft, собранные из
`build279-src/api-src` (взяты из `tools/api271` и дополнены
`isDone/setSpeedModifier/moveTo(DDDID)`, `getDeltaMovement/setDeltaMovement`,
`xxa/yya/zza/getMoveControl`, `MoveControl`, `getDouble/putDouble`).

## Что проверить в игре

1. Нода «+ Преследование» → `trigger:pursuit:start:npc:|1.6|8.0`, инспектор:
   «Тип цели / Цель / Дистанция / Догонять с / Завершить преследование /
   Удалить исходя / Удалить узел».
2. Вписать цель, поставить «Дистанция» 2.0 — NPC подходит и останавливается в
   двух блоках, вплотную не заходит, не толкает игрока.
3. Побежать от NPC: он ускоряется и догоняет, снова останавливаясь на
   дистанции; вернуться вплотную к нему — NPC не отходит и не заходит в игрока.
4. Поставить «Дистанция» 1.0 и 4.0 — поведение меняется соответственно.
5. Выйти из мира и зайти снова во время преследования — дистанция та же.
6. Нода, созданная в 278 (без `|…`), ведёт себя как 1.6 / 8.0.
