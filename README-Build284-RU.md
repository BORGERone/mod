# SettledLands 0.8.0 — Build 284 «Синие провода значения и вход цели»

Три правки по ноде преследования: провод значения стал цельным и синим, у ноды
появился вход цели.

---

## 1. Провод был рваным

В 283 провод рисовался штрихами: 26 отсчётов по кривой, каждый второй
пропускался, и каждый штрих — квадратик 2×2 пикселя.

```java
int steps = 26;
for (int i = 0; i < steps; i++) {
    if ((i & 1) == 1) continue;          // <- половина отсчётов выброшена
    ...
    graphics.fill(sx - 1, sy - 1, sx + 1, sy + 1, color);   // <- точки, а не линия
}
```

Отсюда «не цельно, рвано, мало блоков»: между точками оставались дыры, а шаг
зависел от длины провода.

## 2. Что сделано с проводом

Теперь это один кубический провод с горизонтальными касательными на обоих концах
(как кабели самого холста), с шагом примерно в один экранный пиксель и заливкой
коротких участков, поэтому он непрерывен при любом зуме:

```java
double reach = Math.max(36.0D, Math.abs(dx) * 0.45D);
int steps = clamp((|dx| + |dy|) * 0.5, 16, 240);
// P0, P1 = P0 + (reach, 0), P2 = P3 - (reach, 0), P3
pixelRun(graphics, previousX, previousY, x, y, color);   // без разрывов
```

Цвет один для всего, что несёт значение: **синий** `#4C8DFE` (ромбы и текст на
карточке — `#6FB6FF`). Провод выполнения остался как был: он принадлежит холсту и
цвет значит другое.

## 3. Вход цели

У карточки был только выход значения. Теперь есть и парный вход — синий ромб на
левой кромке, в том же ряду:

```
      ┌──────────────────────────┐
 вх.▸ ┼                          │ ┌ выполнения
      │  Преследование           ├─┘
 ◇ ──▸│  ← Цель: Игрок           ├─┐
      └──────────────────────────┘ ◇ вых. значения
```

* тянете ромб слева и бросаете на другую ноду преследования — эта нода начинает
  следовать её цели;
* бросаете на пустое место — связь снимается, остаётся собственный текст;
* показатель связи — стрелка в строке значения: `←` значение приходит извне,
  `→` текст принадлежит самой ноде.

Значение живёт в действии ноды, поэтому сервер видит актуальный текст: при любом
изменении графа (`changed()`) связанные цели пересчитываются по цепочке (до 8
звеньев) и записываются в действие.

## Как это хранится

Новых полей нет — обе связи дописываются в то же действие:

```
trigger:pursuit:start:npc:<цель>|<дистанция>|<догон>|<ускорение>|@12,15|#3
                                                              получатели ─┘   └─ источник цели
```

`NpcPursuit269` читает три числа по индексу и хвост не разбирает.

## Что проверить

* Провод значения: сплошная синяя линия без разрывов, на любом зуме и длине.
* Резинка при перетаскивании тоже сплошная и синяя.
* Ромб слева тянется, бросание на другую ноду преследования связывает её.
* После связи строка значения показывает `←` и цель источника; правка цели у
  источника меняет её и у получателя.
* Бросание на пустое место снимает связь, возвращается собственный текст.
* Нода по-прежнему работает: `trigger:pursuit:*`, `%pursuit%`, инспектор,
  дистанция, догон. Анимация NPC из 283 не менялась.
