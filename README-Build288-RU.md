# SettledLands 0.8.0 — Build 288 «Синий провод режется средней кнопкой, труп можно преследовать»

## 1. Синий провод нельзя было удалить средней кнопкой

Штатный граф режет кабель под курсором средней кнопкой мыши. У синих проводов
значения был только мой ярлык — правый клик по ромбу, и он снимал сразу все связи
пина, а не один провод. Это не то же самое действие и не то же поведение.

Теперь средняя кнопка ищет **ровно тот провод**, что под курсором, и режет только
его:

* провод ищется по той же кубической кривой, которую рисует сам экран
  (`NpcDialogueGraphScreen#curve`), и с тем же допуском, который холст даёт своим
  кабелям (`NpcGraphCanvas#hitCable`: `max(1.8, min(5.5, 4·zoom + 1.2))`), поэтому
  попадать по проводу так же легко, как по обычному кабелю;
* провод-источник (синий выход → синий вход) отцепляется от входа;
* провод-потребитель (синий выход → другой узел) снимает только этого потребителя;
* нажатие проходит через снимок отмены экрана, как штатное отсоединение, так что
  `Ctrl+Z` его возвращает.

Итог по поведению: перетаскивание, бросок, отрисовка, резка и отмена — полный
набор штатных действий, отличается только цвет. Правый клик по ромбу остался как
ярлык «снять все связи этого пина».

## 2. Нода преследования не шла к трупу с идентификатором

`NpcPursuit269.matches` отбрасывал трупы из сопоставления цели вместе с
NPC-триггерами:

```java
if (!(entity instanceof GuideNpc npc) || npc instanceof GuideCorpseNpc
        || npc instanceof GuideTriggerNpc) return false;
```

Труп — обычный `GuideNpc`, у него есть свой профиль, и ему можно задать
идентификатор, но из-за этой строки цель не находилась вообще: контроллер каждые
20 тиков не находил цель, останавливал движение и ждал. Отсюда «не идёт никуда».

Теперь отбрасываются только триггеры:

```java
if (!(entity instanceof GuideNpc npc) || npc instanceof GuideTriggerNpc) return false;
```

Триггеры остаются исключёнными — это маркеры, а не тела. Труп по-прежнему не может
быть **преследователем**: этот запрет в `NpcPursuit269.run` не тронут.

## Что проверить в игре

1. Средняя кнопка по синему проводу: режется только он. Если у ноды было
   несколько потребителей — остальные провода остаются. `Ctrl+Z` возвращает связь.
2. Труп с идентификатором: нода преследования на NPC с этим идентификатором — NPC
   должен подойти к трупу и держать дистанцию. Если он всё ещё стоит, нужен
   `latest.log`.
3. Непроверенное с 286/287: женский японский рыбак, провод цели при дальнем зуме,
   синий выход → синий вход цели, отсутствие вылета при открытии диалога с правкой.
