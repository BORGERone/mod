# SettledLands 0.8.0 — Build 291 «Починка вылета на запуске из 290»

## Что произошло

Build 290 не запускался: игра падала на загрузке с

```
Mixin apply for mod settledlands failed settledlands.mixins.json:GuideDialogueValue290
Invalid descriptor on ...::settledlands$enterSendGraph(Lnet/minecraft/server/level/ServerPlayer;Ljava/lang/Object;...)
Expected (...Ldev/settledlands/npc/GuideDialogue$Session;...) but found (...Ljava/lang/Object;...)
```

## Почему

В 290 один хук миксина диалога был объявлен с параметром `Object` вместо типа
сессии `GuideDialogue$Session`. Тип сессии package-private, из пакета миксина его
не назвать — я подставил `Object` и понадеялся, что загрузчик стерпит. Он не
стерпит: дескрипторы обработчиков сравниваются буквально, поэтому миксин не
применился, а NeoForge считает неудачное применение миксина фатальным — отсюда
падение при запуске.

Гейты это пропустили: `check_mixin_class` проверял, что цель хука существует, и
что число параметров совпадает, но не сверял их типы.

## Что сделано

1. **Хук переставлен.** Тот же эффект («знать NPC, пока строится вид диалога»)
   теперь даёт `@Redirect` на вызов `GuideNpc#relationTo(ServerPlayer)` внутри
   `sendGraph` — этот метод публичный, вызывается до сборки текста и отдаёт того
   же NPC. Никаких package-private типов в подписи нет.
2. **Гейт расширен.** `tools/check_mixin_class.py` теперь сверяет типы всех
   параметров каждого `@Inject`-обработчика с целевым методом. Проверено на
   прошлой сборке: 290 он теперь валит ровно с этим сообщением, 291 проходит.
3. Больше ничего не менялось: синие входы реплики, триггера, условия и
   переменной, синий выход «Урона» и серверная логика те же, что в 290.

## Что проверить

1. Игра запускается, в списке модов `Settled Lands 0.8.0-build291-launch-fix`.
2. Синий ромб на левой кромке у реплики, триггера, условия и переменной.
3. «Урон» → преследование: ударь NPC, он идёт за тем, кто ударил; через 10 секунд
   без ударов перестаёт.
4. «В радиусе» → «Условие»: `= 1` при теле, `= 0` когда ушло.
5. «В радиусе» → «Реплика» с `%target%`: в диалоге имя тела.

## Гейты

`validate_jar`, `jvm_verify`, `check_mixin_class` (теперь с проверкой типов
параметров), `dangling_refs` — все пройдены. Новых ссылок на Minecraft
относительно 290 нет.
