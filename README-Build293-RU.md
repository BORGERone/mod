# SettledLands 0.8.0 — Build 293 «Защита короткого пути tp»

## Что было

Цепь «В радиусе» → «Триггер» с `tp @npc ~ ~5 ~` в игре шла как

```
/tp @s 8efbfa3e-4db6-4898-85aa-cbe88512f3fb ~ ~5 ~
```

и падала с «Неверный аргумент для команды».

**Почему.** Мод сначала подставляет свои токены: `@npc` → uuid НПС. И только потом
срабатывает короткий путь «цели нет, только координаты — значит телепортируем себя»: если
после `tp` первый символ `~ ^ - 0-9`, дописывается `@s`. UUID начинается с
шестнадцатеричной цифры, поэтому uuid попал в слот координат.

**Почему не помог 292.** В 292 это перекрывалось хуком (`@Redirect`) на вызов
`String.replaceFirst`. Лог с этим запуском показывает, что команда всё равно ушла с `@s`,
то есть хук в игре не сработал. Поэтому в 293 хука нет вообще.

## Что сделано

Правка в самом классе `NpcActions`: заменена строка-шаблон проверки.

```
было   ^(tp|teleport)\s+([~^\-0-9].*)        первая цифра = «координаты»
стало  ^(tp|teleport)\s+[~^\-0-9.]*(\s.*)?   координатой должно быть всё слово
```

Теперь `8efbfa3e-…`, `@s`, `@p`, `@npc`, ники — не координаты, `@s` к ним не дописывается.
`tp ~ ~5 ~`, `tp 100 64 100`, `tp -3 5 2`, `tp 1.5 2.0 3.0`, `tp ~ ~5 ~ facing entity @p`
остаются как были: мод сам ставит `@s`.

Технически это одна строка в пуле констант класса. В class-файле нет абсолютных смещений —
всё читается последовательно, поэтому длина строки меняется без сдвига остального кода.
Сборщик проверяет, что строка в пуле ровно одна и что её читают ровно два места
(`command`, `commandForEntity`); класс дополнительно распарсен JDK-парсером class-файлов.

## Что проверить

1. `tp @npc ~ ~5 ~` в триггере → НПС поднимается на 5 блоков, ошибки нет.
2. `tp @s ~ ~5 ~` → поднимается игрок, от чьего имени идёт триггер.
3. `tp ~ ~5 ~` без цели → поднимается игрок (мод сам ставит `@s`).
4. `effect give @p minecraft:speed 10 1` → без изменений.

В списке модов имя должно быть `Settled Lands 0.8.0-build293-tp-target-guard`.

## Гейты

`validate_jar`, `jvm_verify`, `check_mixin_class` (38 миксинов), `dangling_refs`,
`verify_jar` — пройдены. Новых классов нет, новых ссылок на Minecraft нет. Шаблон прогнан
на наборе строк: uuid, селекторы, ники, целые и дробные координаты, `facing`, посторонние
команды.
