# SettledLands 0.8.0 — Build 294 «В радиусе → Условие: обе ветки»

## Что было

Цепь: «В радиусе» #4 (Цель: Игрок, Радиус 5, Кулдаун 5 с) → «Условие» #5 (`#4 == 0`),
True → триггер `say true`, False → триггер `say false`.

- в радиусе кто-то есть → печатается `false` (ветка False работает);
- в радиусе никого нет → **не происходит ничего**.

**Почему.** Обход графа (`GuideDialogue#resolveExecutionTarget`) считает «В радиусе»
воротами: если `checkProximityCondition` вернула `false`, он тут же ставит следующий
узел `-1` — обход заканчивается на #4. Условие #5 в этот момент просто не
выполняется, поэтому оно ни разу не видело ноль. Само значение ноды читается отдельно
(`NpcValueSource290#ifValue` → `NpcCheckValue289#detected`) и пустой радиус как раз и
означает 0 — но ответ до условия не доходил: до него не доходил обход.

## Что сделано

Один хук: `GuideDialogueCheckGate294` (`@Redirect` на `checkProximityCondition` внутри
`resolveExecutionTarget`) плюс новая функция `NpcValueSource290#passThroughWhenValue`.

```
check прошла                          → как раньше: true, действие, триггеры, next
check не прошла, нода не связана синью → как раньше: false, обход заканчивается
check не прошла, нода питает синий вход, своего действия у ноды нет
                                      → обход идёт дальше по next, значение 0
```

Что при этом не меняется:

- своё действие ноды и её список триггеров на неудачной проверке по-прежнему **не**
  выполняются — до потребителя доходит только значение (метка `PENDING` гасит вызов
  триггеров именно этой ноды);
- нода «В радиусе» со своим действием остаётся воротами: нашлась цель — выполняем,
  не нашлась — цепь заканчивается, как и было;
- граф без синих проводов работает ровно как раньше.

## Что проверить

1. Цепь #4 → #5 (`#4 == 0`), True → `say true`, False → `say false`:
   никого в радиусе → `true`; кто-то в радиусе → `false`. Каждые 5 с по кулдауну ноды.
2. «В радиусе» без синего провода, как ворота перед «Триггером»: никого — ничего не
   происходит (как раньше).
3. «В радиусе» со своим действием в поле «Триггер / действие»: никого — ничего, кто-то
   есть — действие выполняется (как раньше).

В списке модов имя должно быть `Settled Lands 0.8.0-build294-radius-if-branch`.
