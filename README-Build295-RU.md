# SettledLands 0.8.0 — Build 295 «Пустой радиус: цепь всё равно идёт»

## Что было (после 294)

Та же цепь: «В радиусе» #4 (Цель: Игрок, Радиус 5, Кулдаун 5 с) → «Условие» #5 (`#4 == 0`),
True → `say true`, False → `say false`. Кто-то в радиусе — печатается ветка False; никого —
по-прежнему ничего.

**Почему 294 не помогла.** В логе видно устройство механизма:

```
[graph] check node #4 target 0 radius 5 scanning...     (каждые 0.5 с)
[graph] check node #4 FIRED on BORGER
[graph] walk starts at node #5 for BORGER
```

Нода «В радиусе» — не звено обхода, а сканер: `tickGraphCheckNodes` сам опрашивает радиус и,
**только если кого-то нашёл**, запускает цепь — причём сразу со следующей ноды (#5), а не с #4.
Когда в радиусе пусто, цепь не начинается вообще. Правка 294 стояла внутри обхода и срабатывала
только если обход до ноды #4 доходил — а он до неё не доходил никогда. Поэтому поведение не
изменилось.

## Что сделано

Новый хук `GuideNpcEmptyCheck295` — `@Inject(HEAD)` на `GuideNpc#customServerAiStep` (это тот
самый серверный тик, откуда и вызывается `tickGraphCheckNodes`) — и `NpcValueSource290#tickEmptyChecks`.
Раз в 10 тиков, по каждой ноде графа:

```
радиус пуст (NpcCheckValue289.detected == null)   → цепь стартует с node.next без инициатора
кто-то есть                                        → ничего не делаем, этим занят штатный обход
кто-то есть, но у него свой кулдаун               → тоже ничего: тело в радиусе есть, значит и значение не 0
кулдаун ноды (5 с) не вышел                        → пропускаем
у ноды своё действие                               → пропускаем: это ворота с полезной нагрузкой
нода не питает синий вход                          → пропускаем: такие графы не трогаем
```

Дальше всё как раньше: обход доходит до «Условия» #5, значение синего входа = 0, `#4 == 0`
истинно, срабатывает ветка True (`say true`). Своё действие ноды #4 и её список триггеров на
пустом проходе не выполняются.

Нода #4 не меняется, её кулдаун 5 с остаётся тем же — пустая ветка печатается не чаще, чем раз
в 5 секунд.

## Что проверить

1. Цепь #4 → #5 (`#4 == 0`): **никого** в радиусе → `true`; **кто-то** в радиусе → `false`.
2. Стоять внутри радиуса: ветка False, без повторов чаще кулдауна.
3. Выйти из радиуса: через ~5 с печатается `true`.
4. В `latest.log` при первом пустом проходе появляется одна строка
   `[settledlands] [graph] empty radius #4: chain starts at node #5` — она доказывает, что хук
   работает; дальше он молчит.
5. «В радиусе» без синего провода, как ворота перед триггером: никого — ничего (как раньше).

В списке модов имя должно быть `Settled Lands 0.8.0-build295-empty-radius-chain`.
