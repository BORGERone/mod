# SettledLands 0.8.0 — Build 296 «Откат 295»

## Что было

295 сломала ноду условия. Причина: хук 295 запускал цепь из пустого радиуса **без тела**,
с `null` вместо игрока. Нода условия считалась «ни для кого» — а она должна считаться для того
тела, которое нашла нода «В радиусе». Отсюда поломка: условие перестало работать так, как
работало.

Отдельно зафиксировано, как эта цепь устроена по замыслу (и это не то, что делали 294/295):

- нода «В радиусе» находит игрока в радиусе и отдаёт ноде условия **этого игрока** (его id);
- нода условия читает **переменную этого игрока** и по результату сравнения выводит True/False.

Ни 294, ни 295 этого не реализуют: 294 подменяла проверку на «есть тело / нет тела» (1/0),
295 вдобавок запускала её вообще без тела. Поэтому 295 отменена целиком.

## Что сделано

Полный откат. В этом jar лежит код 294 без единого изменения класса:

```
изменены только META-INF/neoforge.mods.toml и settledlands-patch-info.txt
классов добавлено / заменено / удалено: 0
содержимое 294 и 296 совпадает побайтно во всех 454 записях, кроме этих двух
```

Нода «В радиусе» ведёт себя как в 294, нода условия — как до 295. Ничего другого не тронуто.

## Что проверить

1. Цепь #4 → #5 работает как раньше: кто-то в радиусе — ветка условия срабатывает, как до 295.
2. Нода условия больше не «залипает» и не срабатывает сама по себе при пустом радиусе.
3. В списке модов имя `Settled Lands 0.8.0-build296-revert-295`.
