# SettledLands 0.8.0 — Build 298 «Провод не переписывает условие»

## Что было

После подключения синего провода от «В радиусе» карточка условия показывала вместо
`? кукт == 0` — `? #4 == 0`, и казалось, что условие начало сравнивать номер ноды с нулём.

## Почему

Серверная часть уже была верной (после 297): и `evalIfNode`, и ветка IF в
`resolveExecutionTarget` берут имя переменной у подключённой ноды **только если это нода
«Переменная»** (тип 4). Для ноды «В радиусе» имя не подменяется — читается собственная
переменная условия, у того игрока, которого ведёт цепь (его нашла нода радиуса).

Врала карточка. В `NpcDialogueGraphScreen#drawNode` для ноды условия с `varInputNode >= 0`
рисуется имя переменной подключённой ноды, а если у неё имени нет — подставляется `#<id>`.
У ноды «В радиусе» имени нет, отсюда `#4`. В 290 связь пряталась только на время прохода
кабелей, а карточки рисуются после — к этому моменту связь уже была восстановлена.

## Что сделано

Связь вынимается из `varInputNode` на весь кадр: на входе `render` и возвращается на выходе.
Что это даёт:

```
карточка условия    → своя переменная, свой оператор, своё число (кукт == 0)
родной проход проводов → в поле входа условия больше не рисуется лишний кабель
синий проход        → по-прежнему рисует свой кабель от пина ноды-источника
сохранённая связь   → не тронута: возвращается в том же кадре
сервер              → без изменений
```

Хелпер `PursuitGraphNode272` получил `beginStockInputHide` (сначала восстанавливает кадр,
который не успел прибраться), `stockInputSource` (по нему синий проход рисует кабель, пока
связь спрятана) и идемпотентный `hideStockInputWires` — второй вызов в том же кадре ничего
не затирает.

## Что проверить

1. Подключить «В радиусе» #4 к условию: на карточке остаётся `кукт == 0` (или своя
   переменная), `#4` не появляется.
2. Условие срабатывает по значению `кукт` у игрока, которого нашла нода #4: True при
   `кукт == 0`, False при другом значении.
3. Отключить провод — карточка и поведение условия те же.
4. Синий кабель от пина #4 к полю входа условия на месте, второго (серого) кабеля нет.
5. Нода условия без провода и связка через ноду «Переменная» работают как раньше.
6. В списке модов имя `Settled Lands 0.8.0-build298-if-card-keeps-variable`.
