# SettledLands 0.8.0 — Build 299 «Карточка условия не меняется, провода не лагают»

## Что было

На 298 карточка условия по-прежнему превращалась в `#4 == 0` после подключения синего провода,
и появился лаг отрисовки синего провода.

## Почему 298 не сработала и почему был лаг

1. **Не та точка.** Я думал, что карточка любой ноды идёт через `PursuitGraphNode272#drawNode`.
   По байткоду это не так: мост-перехват вызывает его **только для нод pursuit**. Обычная нода
   условия рисуется штатным `NpcDialogueGraphScreen#drawNode` напрямую, и моя правка её не
   касалась вообще.
2. **Лаг.** 298 снимала связь `varInputNode` на весь кадр (от `render` HEAD до `render` TAIL).
   Проход проводов в этом кадре видел граф в другом состоянии, чем всё остальное, и перерисовывался
   каждый кадр в подвижном состоянии — отсюда рывки.

## Что сделано

Правка привязана к самой отрисовке карточки и живёт ровно один вызов:

```
drawNode HEAD   → связь «тело» снимается с ноды
drawNode RETURN → связь возвращается (та же величина, то же поле)
```

Плюс те же два места, что и раньше, но тоже с гарантированным возвратом:

```
widgets()  HEAD/TAIL → боковая панель строится без «вход связан с #4»
wires()    HEAD      → связь снимается на время прохода кабелей
wires()    TAIL      → синий проход рисует кабели и в finally возвращает связь
```

Счётчик вложенности (`HIDE_DEPTH`) не даёт внутреннему вызову вернуть связь раньше внешнего, а
`beginWiresPass` убирает возможный «зависший» проход с предыдущего кадра. Между кадрами граф
всегда в сохранённом состоянии — поэтому лага нет.

Связь с нодой **«Переменная»** — это настоящая связь переменной, её не трогаем нигде: карточка
показывает имя той переменной, как и раньше.

## Что проверить

1. Подключить «В радиусе» #4 к условию: на карточке **остаётся** `кукт == 0` (или своя переменная),
   `#4` не появляется ни на карточке, ни в боковой панели.
2. Провод при перетаскивании и в покое рисуется плавно, без рывков и мигания.
3. Условие срабатывает по значению `кукт` у игрока из радиуса: True при `кукт == 0`, False при другом.
4. Отключить провод — карточка и поведение те же; связка через ноду «Переменная» работает как раньше.
5. В списке модов имя `Settled Lands 0.8.0-build299-if-card-scoped`.
