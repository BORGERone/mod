# SettledLands 0.8.0 — Build 300 «Провод рисуется всегда, пин — круглая точка»

## Что было

После 299 условие считается правильно, но синий провод отображался неверно: он пропадал и
появлялся, из-за чего выглядел «залаганным». Плюс пин был большим плюсом.

## Почему провод пропадал

Нашёл в коде, не на глаз:

1. В 299 связь `varInputNode` снимается с ноды на время прохода кабелей (и в боковой панели), а
   возвращается в конце.
2. Проверка «есть ли вообще синие провода» — `hasValueWires` — читала **то же поле**, которое в
   этот момент пустое. Проход решал «проводов нет» и не рисовал ничего. Провод появлялся только
   при перетаскивании (там проверка выходит раньше по `dragOut`) — отсюда «лаг».
3. Тем же чтением пользовался счётчик подключений у пина — он тоже врал.
4. Плюс к этому скрытие связи для карточки было непарным: оно срабатывало на входе `drawNode` и
   для нод pursuit, которые рисует мост с отменой метода — возврат на выходе не вызывался, и
   скрытие перетекало в следующий кадр.

## Что сделано

```
hasValueWires, wiredTo   → спрашивают stockInputSource (учитывает временно снятую связь)
скрытие для карточки     → только для обычных нод; ноды pursuit пропускаются (пара всегда парная)
начало кадра             → только восстановление, если что-то осталось снятым (ничего не прячет,
                           поэтому мерцания быть не может)
синие пины               → круглая точка радиусом 3 вместо плюса 11×11:
                           выход «В радиусе» / «Урон», входы реплики/триггера/условия/переменной,
                           оба пина карточки pursuit
радиус захвата пина      → 5 px, по нарисованной точке
```

## Что проверить

1. Подключить «В радиусе» #4 к условию: синий провод **виден постоянно**, не мигает и не исчезает
   при движении мыши или перетаскивании ноды.
2. Пин на карточке — маленький синий кружок, не крестик; захватывается мышью как раньше.
3. Условие продолжает работать по своей переменной (`кукт == 0`), карточка не показывает `#4`.
4. Отключить провод (ПКМ по ноде-источнику или средняя кнопка по проводу) — провод исчезает,
   счётчик у пина тоже.
5. Перезапустить мир и открыть граф: связь на месте (проверка на «протёкшее» скрытие).
6. В списке модов имя `Settled Lands 0.8.0-build300-wire-and-pin`.
