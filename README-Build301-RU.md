# SettledLands 0.8.0 — Build 301 «Маленькие синие пины и белая обычная проводка»

## Что сделано

### Синие пины

Было: радиус в экранных пикселях, поэтому при отдалении пин выглядел огромным, при приближении —
крошечным.

Стало — та же логика, что у обычных портов карточки:

```
радиус = 2.0 (единицы карточки) × зум
координаты = позиция ноды на экране + смещение в единицах карточки
радиус захвата мышью = max(3.0, 5.0 × зум)
```

Вдвое меньше обычного порта (тот 10×10), круглый, растёт и уменьшается вместе с карточкой.
Пины карточки pursuit теперь тоже рисуются после её трансформации — тем же правилом, что и на
обычных нодах, поэтому ведут себя одинаково.

### Белая обычная проводка

```
порты карточек (квадраты 10×10 по краям)  → белые (0xFFF2F2F2)
кабели между нодами                       → белые (0xFFE8E8E8)
резиновая линия при перетаскивании        → белая
синие провода значений                    → остались синими
корпус карточки, заголовок, подписи       → не тронуты
```

Порты белятся узким фильтром: подменяется только заливка прямоугольника ровно 10×10 на левом или
правом краю карточки шириной 220 — остальные заливки проходят без изменений. Кабели — через седьмой
аргумент (цвет) у `cable`/`curve` в проходе проводов, поэтому закрыты все: обычные линии, линии по
отношению и резиновая при перетаскивании.

## Что проверить

1. Синий пин на «В радиусе» — маленький кружок; при приближении/отдалении меняется вместе с
   карточкой, тянется мышью так же.
2. Все обычные порты на карточках белые, вне зависимости от типа ноды; цветных нет.
3. Кабели между нодами белые, в том числе линия при перетаскивании; при наведении/резании ведут
   себя как раньше.
4. Синие провода значений остались синими и по-прежнему видны постоянно.
5. Карточки, текст и заголовки выглядят как раньше.
6. В списке модов имя `Settled Lands 0.8.0-build301-pins-and-white-wiring`.
