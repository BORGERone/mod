# SettledLands 0.8.0 — Build 304 «Рабочая область нод как в Gadgets & Gizmos»

## Что взято

Редактор нод у G&G — это Advanced Contraption Controller / Advanced Control Computer. Его
публичные исходники открыты, оттуда взяты палитра по умолчанию и геометрия:

```
холст          #0D1215, точки #1B2429 через 24 единицы графа (едут вместе с паном)
панель/карточка #202A2F      рамка #39464C      рамка мягкая #2C373D
акцент         #C6873F       акцент светлый #E2AA63
текст          #E8E0CD       вторичный #C7C0B2   приглушённый #918C82
опасность      #BD6559
карточка       220×100 единиц, шапка 22, порт 10×10 по центру высоты
```

## Что сделано

```
холст            → тёмный фон + сетка точками вместо линий (grid)
карточка         → рамка 1 px, акцентная полоса по верхней кромке, выбранная — янтарная
порты            → круглые: тёмный ободок + светлая точка, вместо цветных квадратов 10×10
карточка pursuit → та же рамка и те же порты, палитра темы (было: фиолетовая шапка)
кабели           → тёплый серый темы #C7C0B2
синие провода    → остались синими
текст, клики, данные графа — не тронуты
```

Все новые хуки висят на **своих** методах экрана (`grid`, `drawNode`), а не на методах
Minecraft — тот вылет из 301/302 здесь невозможен по построению.

## Чего в этой сборке ещё нет

* Шапки карточек пока остаются своих цветов (по типу ноды): перекраска шапки = перерисовка
  заголовка поверх неё, это делается вместе с библиотекой нод.
* Библиотеки нод слева с поиском и меню «добавить ноду» с поиском — следующие сборки.

## Что проверить

1. Холст тёмный, точки едут вместе с полотном при перетаскивании и меняют шаг при зуме.
2. Карточки в тонкой рамке, сверху янтарная полоса; выбранная карточка — янтарная рамка.
3. Порты по краям карточек круглые, светлые; синие пины значений на месте.
4. Кабели тёпло-серые, синие провода значений по-прежнему синие и целые.
5. Текст на карточках читается, ничего не наложилось; клики и перетаскивание как раньше.
