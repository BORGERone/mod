# SettledLands 0.8.0 — Build 305 «Воркспейс нод, а не перекраска»

## Что это

Build 304 перекрашивал старый экран. Этот билд переносит **воркспейс нод**: слой рисования
редактора Advanced Control Computer из «Create Aeronautics: Gadgets & Gizmos» (использован с
разрешения авторов) и библиотеку нод с поиском, в которой живут **наши** ноды.

Код воркспейса — наш. Из G&G взят слой рисования (прямоугольники со скруглением, шапка
карточки, круглые порты, ромбы exec-портов, строки списков, панели, смешивание цвета) и
палитра по умолчанию. Про графы он не знает ничего: ни про их узлы, ни про наши.

```
новые классы
  WorkspaceTheme305     слой рисования воркспейса (перенесён), палитра темы
  NpcNodeLibrary305     библиотека нод: поиск, список, прокрутка, L — скрыть
  NpcLibrary305Mixin    панель на экране графа: отрисовка, клики, клавиши

изменено
  WorkspaceSkin304      холст, точки и все карточки теперь рисует WorkspaceTheme305
```

## Библиотека нод

Слева от холста — панель «Ноды» со списком всех 15 типов:

```
Реплика · Кнопка · Триггер · Условие If · Переменная · В радиусе · Урон · Время
Таймер · Анимация · Задание · Передвижение · Подвижность · Случайность · Катсцена
```

* поле поиска — настоящий `EditBox`, но невидимый: панель сама рисует рамку и текст, а ввод
  идёт через штатный механизм (раскладки, IME, автоповтор). Ищет и по русскому названию, и по
  латинскому алиасу (`line`, `if`, `quest`, `cutscene` …);
* клик по строке добавляет ноду через **штатный** `add(int)` экрана — снимок undo, выделение и
  флаг «есть несохранённые изменения» работают как от кнопок;
* колесо над панелью листает список, `L` скрывает и показывает панель, `Esc` в поле — очистить
  и снять фокус;
* клик внутри панели не доходит до холста: панорама, рамка выделения и провода не срабатывают;
* пока поле в фокусе, `Delete`/`Backspace` правят текст поиска, а не удаляют выбранные ноды.

## Что не менялось

Формат графа, сохранение (`CfgSave`), undo/redo, синие провода значения, белая проводка,
карточка преследования, все инспекторы. Старые диалоги загружаются без миграций.

## Что проверить

1. Открыть граф диалога NPC: слева панель «Ноды» с полем поиска и списком из 15 строк.
2. Набрать `урон` или `quest` — список фильтруется, счётчик справа сверху уменьшается.
3. Клик по строке — нода появляется на холсте, в заголовке «есть несохранённые изменения».
4. Клик по панели не двигает холст; `L` скрывает панель, ещё раз `L` — возвращает.
5. Синие провода значения и белые кабели на месте, карточки с рамкой и круглыми портами.
