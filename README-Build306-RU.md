# SettledLands 0.8.0 — Build 306 «Воркспейс нод — это и есть редактор»

## Что сделано

`NpcDialogueGraphScreen.open(...)` — единственная точка входа, через которую редактор открывают
все (экран конфига, диалог, кнопка «Открыть граф»). Теперь она открывает **наш собственный экран**
`NpcWorkspace306`, который владеет графом. Старый экран никуда не делся: он открывается кнопкой
«Старый редактор» из воркспейса, с тем же графом.

```
+ npc/client/NpcWorkspace306          свой экран: холст, карточки, порты, кабели, ввод
+ mixin/NpcWorkspaceEntry306Mixin     open(...) → воркспейс
```

Из G&G (с разрешения авторов) — слой рисования `WorkspaceTheme305` и раскладка воркспейса.
Кода их графов здесь нет: ни одного их типа ноды, ни их модели, ни их сериализации.

## Что умеет воркспейс

```
холст            тёмный, точка с шагом 24, пан (СКМ), зум к курсору (колесо), «Обзор»
карточки         наши 15 типов, шапка своим цветом, текст/действие/координаты в теле
порты            вход слева, выходы справа: IF — 2 (true/false), RANDOM — по ветвям
кабели           по реальным связям: next, falseNext, varInputNode, choices, triggers,
                 randomBranches; синий — значение, красный — ветка «ложь», лиловый — random
связывание       перетащить с выходного порта на входной; недопустимая связь — отказ
резка кабеля     ПКМ по кабелю
перетаскивание   ЛКМ по карточке, шаг сетки 8, несколько нод рамкой
рамка выделения  ЛКМ по пустому месту
удаление         Delete / Backspace
undo / redo      Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y
вкладки          Главный · Распорядок · Анимации (нет графа — «+ Создать граф»)
библиотека       слева: все 15 типов, поиск (RU и латиница), колесо, L — скрыть
сохранение       Ctrl+S и кнопка «Сохранить» — тем же пакетом CfgSave, формат графа не менялся
выход            «Назад» / Esc, несохранённое сохраняется при выходе
```

Геометрия портов и попаданий — та же, что у `NpcGraphCanvas` (`portScreenX/Y`, `hit`, `hitPort`,
`hitCable`, `move`), поэтому карточки, порты и клики совпадают с моделью графа.

## Чего ещё нет

* Инспектор полей внутри воркспейса — пока поля правятся в старом редакторе (кнопка есть).
* Меню «добавить ноду» по правой кнопке на холсте с поиском (сейчас — библиотека слева).

## Что проверить

1. Открыть граф диалога NPC — открывается воркспейс, а не старый экран.
2. Карточки на месте, кабели идут по связям; синие провода значения — синие.
3. Перетащить карточку — едет по сетке; рамкой выделяются несколько.
4. Протянуть с выхода «Реплики» на вход другой — кабель появился, «Сохранить» ушло на сервер.
5. ПКМ по кабелю — связь пропала.
6. Вкладка «Распорядок» на NPC без графа распорядка — «+ Создать граф».
7. «Старый редактор» — открывается прежний экран с тем же графом.
8. Закрыть без сохранения — граф сохранился сам (Esc/«Назад»).
