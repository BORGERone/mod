# SettledLands 0.8.0 — Build 307 «Воркспейс открывается»

## Что было

306 роняла клиент на первом же кадре воркспейса:

```
java.lang.ArrayIndexOutOfBoundsException: Index 6 out of bounds for length 6
    at dev.settledlands.npc.client.NpcWorkspace306.drawTopBar(NpcWorkspace306.java:370)
```

Верхняя панель держит три вкладки и три кнопки в одной таблице подписей, а подпись читалась по
«номер действия + 1». Последняя кнопка («Назад») просила седьмую запись из шести — вылет до того,
как что-то успевало отрисоваться.

## Что исправлено

```
подпись кнопки    читается по номеру действия и зажата в границы таблицы (сам вылет)
добавление ноды   координаты зажимаются лимитом модели MAX_COORD (панорама далеко в сторону)
связь порт→порт   отказ connect(...) ловится, а не роняет экран
undo              битый снимок игнорируется вместо падения
```

## Почему это не повторится

Добавлен шестой гейт — `tools/screen_smoke.py`: экран прогоняется в обычной JVM, без игры.
Стабы компиляции подставляются как настоящие классы, `Minecraft`, `Font`, `Screen` и
`CompoundTag` берутся из `tools/harness`, а драйвер строит граф со всеми 15 типами нод и всеми
видами связей и дёргает экран как игрок: конструктор, `init`, ресайз, отрисовка, клики, драг,
рамка, связь, резка, колесо, поиск, ввод, undo/redo, удаление, переключение вкладок.

```
python3 tools/screen_smoke.py settledlands-0.8.0-build306-workspace.jar   → FAILURES: 7
python3 tools/screen_smoke.py settledlands-0.8.0-build307-workspace-render.jar → OK, 37 шагов
```

Проверка на прошлой сборке падает ровно там же, где падала игра.

## Что проверить в игре

1. Открыть диалог с правкой — воркспейс открывается, а не закрывается.
2. Вкладки «Главный / Распорядок / Анимации» переключаются, «Анимации» на NPC без графа показывает «+ Создать граф».
3. Библиотека слева: поиск, клик по строке добавляет ноду.
4. Карточка тянется, рамка выделяет, связь с выхода на вход появляется, ПКМ по кабелю её режет.
5. «Сохранить» — статус «Отправлено серверу…»; «Старый редактор» — прежний экран с тем же графом.
