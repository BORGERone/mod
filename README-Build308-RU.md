# SettledLands 0.8.0 — Build 308 «Откат к нашему виду нод»

## Что сделано

Откат к редактору из 304 — тому виду нод, который уже работал в игре. Сборка сделана прямо от
jar 304: отдельный экран воркспейса, его миксин и панель библиотеки в неё не входят вообще.

```
убрано        NpcWorkspace306, NpcWorkspaceEntry306Mixin, NpcLibrary305Mixin, WorkspaceTheme305,
              NpcNodeLibrary305 и ключи gui.settledlands.workspace.*
осталось      штатный экран диалога + скин 304: тёмный холст в точку, карточки с рамкой,
              круглые порты, тёплый цвет кабелей, синие провода значения
инспекторы    все на месте, поля правятся как раньше
граф          формат, сохранение и пакет CfgSave — не менялись
```

Версия и displayName подняты, чтобы лаунчер видел замену файла.

## Что осталось в репозитории, но не в сборке

* `tools/screen_smoke.py` + `tools/harness/` — прогон экрана в обычной JVM без игры. На jar без
  экрана воркспейса гейт пишет `SKIP`, поэтому в текущей сборке он ничего не проверяет, но
  останется полезным, если появится новый экран.
* Исходники 306/307 лежат в истории git (`build305-src/src/...`), в сборку и в архив 308 не входят.

## Что проверить

1. Граф диалога открывается штатным экраном: тёмный холст, карточки, круглые порты, тёплые кабели.
2. Синие провода значения на месте.
3. Инспектор выбранной ноды справа работает как раньше.
4. Сохранение пишет «Отправлено серверу…».
