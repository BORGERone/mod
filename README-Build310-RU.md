# SettledLands 0.8.0 — Build 310 «Синий провод от ноды Урон»

## Причина

Синий провод из «Урона» в синий вход ноды преследования **сохранялся в графе** и работал на
сервере (NPC преследовал того, кто его ударил), но на холсте не рисовался.

В `NpcPursuitValuePinMixin290` два места смотрят на источник провода у входа преследования —
рисование и резка средней кнопкой — и оба спрашивали `isCheckValueNode(from)`, то есть «это нода
В радиусе?». Для ноды «Урон» ответ ложный, ветка не срабатывала, провод не появлялся. Средняя
кнопка по такому проводу тоже не работала.

## Что изменено

```
NpcPursuitValuePinMixin290.java
  settledlands$paintValueWires   isCheckValueNode(from)  ->  isValueSourceNode(from)
  settledlands$cutValueWire      isCheckValueNode(from)  ->  isValueSourceNode(from)
```

`isValueSourceNode` = «В радиусе» **или** «Урон». Больше ничего не тронуто: формат графа,
сохранение, серверная часть, откат 309 — как были.

## Гейт

Добавлен `tools/blue_wire_check.py`: читает отправленный класс и падает, если рисование или
резка проверяют только один из источников.

```
309  FAIL  paintValueWires/cutValueWire tests isCheckValueNode
310  OK    draw and cut both accept any blue output
```

## Что проверить

1. Тянуть синий пин из «Урона» в синий вход ноды преследования — провод появляется сразу.
2. Средняя кнопка по этому проводу — режет его.
3. Провод «В радиусе» → преследование по-прежнему рисуется и режется.
