# SettledLands 0.8.0 — Build 312 «Темп преследования и рваное движение»

Обе жалобы — последствия 311. 311 исправил две настоящие ошибки, но перестарался по обеим.

## 1. Слишком быстро

```
                       обычная ходьба   преследование        догон
311  0.10                          1.6× (0.16)         1.4…1.9×  ->  1.6×…3.04×
312  0.10                          1.15× (0.115)       1.25× + 60% от boost  ->  1.25×…2.45×
```
При boost 1.5 (значение по умолчанию в ноде) догон теперь ×1.55 вместо ×1.9, максимум ×2.45 вместо
×3.04. В блоках в секунду: ходьба 2.0, преследование 2.3, догон 2.5–4.9.

## 2. Рваное движение: «останавливается, поворачивается, идёт»

Три места тормозили идущее тело:

```
перестройка пути    путь пересобирался каждый раз, когда цель сместилась на 2 блока
                    (реально — раз в 20 тиков, на бегу почти постоянно). Каждая
                    пересборка выбрасывает текущий путь: NPC останавливается,
                    доворачивает и снова трогается.
смена режима        при переходе в догон/из догона вызывался stopMotion -> обнуление
                    движения, рывок.
откат после провала путь не находился -> пауза 20/40/80/160 тиков; всё это время NPC
                    стоял (до 8 секунд).
```

Что теперь:

```
путь       держится до конца; пересборка — только в догоне, когда цель ушла от точки
           пути на 3 блока, и не чаще раза в 10 тиков
режим      смена режима путь сбрасывает, но тело не тормозит
откат      20 или 40 тиков, не больше двух секунд
сторож     при отсутствии прогресса больше не обнуляет движение
дистанция  возобновление ходьбы после остановки — с 2.6 блока вместо 2.35
```

Анимация (NpcLocoDriver283, 283-я сборка) считает фазу шага по реально пройденному расстоянию,
поэтому рывки в движении давали рывки в анимации. Убрали рывки — ушла и рваная анимация.

## Гейт

`tools/pursuit_check.py` теперь проверяет и темп: читает константы из отправленного класса.

```
311  FAIL  нет PURSUIT_WALK/REPATH_SUCCESS_TICKS, RETRY_MAX_SHIFT = 3
312  OK    PURSUIT_WALK 1.15, CATCH_UP_EXTRA 1.25, RETRY_MAX_SHIFT 1,
           REPATH_SUCCESS_TICKS 10, RESUME_MARGIN 1.0
```

## Что проверить

1. Удар → NPC идёт за игроком ровно, без остановок на поворотах и без рывков.
2. Скорость — чуть быстрее обычной ходьбы, не бег.
3. Отбежать далеко — ускоряется, но не телепортируется.
4. Подойти близко — останавливается на 1.6 блока и не дёргается туда-сюда.
