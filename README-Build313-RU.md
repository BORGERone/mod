# SettledLands 0.8.0 — Build 313 «Идёт не останавливаясь, пока идёт цель»

## Почему «обрывается как спутник в Скайриме»

Преследование считало себя **прибывшим**, как только подходило на дистанцию из ноды (у тебя
1.6 блока), и тормозило: `stopMotion` + ранний выход из тика. Возобновляло шаг только когда цель
уходила ещё на 0.75 сверху — то есть на 2.35 блока.

Идущий игрок проходит этот зазор примерно за секунду. Получался цикл: догнал → встал → игрок ушёл
на 0.75 → снова пошёл. Со стороны — «идёт и останавливается, ждёт тебя», как эскорт.

Второе место: когда путь заканчивался, новый строился только после того, как цель сместится на
**3 блока** (и после отката). Между двумя путями тело стояло.

## Что изменено

```
цель идёт?      каждый тик запоминается position цели; смещение > 0.1 блока/тик
                = цель идёт (TARGET_MOVING_SQ = 0.01)
прибыл          «прибыл» ставится ТОЛЬКО когда цель стоит. Пока цель идёт,
                преследование не тормозит вообще
конец пути      если цель сместилась хотя бы на 0.5 блока — новый путь сразу
                (FOLLOW_STEP_SQ = 0.25). Стоим только когда мы у цели и цель стоит
далеко          если тело застряло далеко от стоящей цели, путь всё равно
                перестраивается по откату (20/40 тиков), а не «замирает навсегда»
RESUME_MARGIN   обратно 0.75 (он больше не влияет на бег: стоп только по неподвижной цели)
```

Скорость и темп из 312 не тронуты: ходьба 1.15×, догон 1.25…2.45×.

## Гейт

`tools/pursuit_check.py` дополнен: требует `movedBy`, `TARGET_MOVING_SQ` и `FOLLOW_STEP_SQ`,
и проверяет их числовые значения из класса.

```
312  FAIL  нет movedBy/TARGET_MOVING_SQ/FOLLOW_STEP_SQ
313  OK
```

## Что проверить

1. Ударить NPC и просто идти — он идёт за тобой непрерывно, без остановок и поджиданий.
2. Остановиться — он подходит на 1.6 блока и встаёт.
3. Снова пойти — трогается сразу, без паузы.
4. Обойти препятствие — не замирает, продолжает искать путь.
