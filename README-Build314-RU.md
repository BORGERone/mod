## 2. Почему анимация рваная (и почему у TnM плавно)

`NpcLocoDriver283` мерил скорость NPC **раз в кадр** по позиции. Но позиция моба на клиенте
меняется **раз в тик**: два кадра — ноль, третий — сразу 0.2 блока. Эта ступенька шла прямо в:

```
фазу шага      ноги двигались 20 ступеньками в секунду вместо непрерывного цикла
вес бленда    0 → 0.8 скачком, отсюда «нет перехода» между стойкой/ходьбой/бегом
```

TnM читает те же величины, но у него они приходят от игрока — с интерполяцией по кадрам,
поэтому у него всё процедурно и плавно.

**Что сделано:**

```
скорость      сглаживается за 60 мс (SPEED_SECONDS), ступенька исчезает
фаза шага     идёт по сглаженной скорости, а не по разнице позиций между кадрами
переходы      120 мс на разгон, 300 мс на затухание (было 80/180)
читатели      новый миксин NpcLocoInputsMixin314: position(partialTick) и speed(partialTick)
              у самого WalkAnimationState отдают сглаженные значения — их получает и TnM,
              а не только мост. Остальные сущности и моды видят ровно то, что видели
```

Миксин отвечает только за состояния, которые драйвер реально сэмплировал (для остальных
`NpcLocoDriver283` возвращает `NaN` и вызывается ванильное значение).

## Что проверить

1. NPC идёт за тобой медленнее, чем в 313, но быстрее обычной ходьбы.
2. Ноги двигаются непрерывно, без рывков, на любой скорости.
3. Переход стоять → идти → бежать — плавный, без скачков.
4. Остановка — плавное затухание, а не стоп-кадр.
