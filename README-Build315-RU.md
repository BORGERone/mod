# SettledLands 0.8.0 — Build 315 «Переход между анимациями»

## Что было не так

Переключение анимации записывало **всю новую позу в модель за один кадр**. Рука была на 80°,
на следующем кадре — на −20°. Это и есть «телепорт» между анимациями: не медленный переход, а
мгновенная подмена позы.

## Что сделано

Любая поза — полная анимация или частичная маска — попадает в модель через одно место:
`NpcMotionBridge256.Pose#set(ModelPart)`. Сразу за ним теперь стоит фильтр `NpcPoseBlend315`:
значения, которые клип только что записал, смешиваются со значениями, которые у части тела были
на прошлом кадре.

```
постоянная времени   90 мс (FADE_SECONDS)
что сглаживается     9 чисел на часть тела: смещение x/y/z, повороты x/y/z, масштаб x/y/z
когда сброс         первый кадр части тела, пауза больше 250 мс (телепорт камеры/загрузка)
чего не трогает     части тела, которыми не управляет ни один клип
```

Это тот же класс техники, что у TnM: у него процедурность — это покадровое смешивание весов по
костям. Здесь такое смешивание добавлено и на наш слой анимаций, поэтому:

* переключение одной анимации на другую больше не рвётся;
* перезапуск той же анимации не даёт скачка в первый кадр;
* выход из частичной маски (когда двигается только часть тела) плавно возвращается;
* кость, переопределённая на один кадр, не дёргается.

Вместе с 314 (сглаженная скорость и фаза шага, которую теперь читает и TnM) это закрывает обе
причины рывков: ступенчатый вход локомоции и мгновенную подмену позы.

## Гейт

`tools/pursuit_check.py` требует наличие `NpcPoseBlend315` и `NpcPoseBlendMixin315` в клиентском
списке миксинов.

```
314  FAIL  анимации не смешиваются
315  OK
```

## Что проверить

1. Переключить NPC с одной анимации на другую (граф, вкладка «Анимации») — переход плавный.
2. Остановить анимацию — поза возвращается, а не прыгает.
3. Та же анимация повторно — без скачка в первый кадр.
4. Ходьба и развороты — без дёрганья (это из 314).

Если какие-то переходы всё ещё рвутся — скажи, какие именно (например «стоять → идёт» или
«анимация из вкладки Анимации → стойка»): это подскажет, чей это слой, наш клип или сам TnM.
