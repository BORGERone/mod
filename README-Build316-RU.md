# SettledLands 0.8.0 — Build 316 «Ноги по скорости и без сброса в idle»

## 1. Ноги двигались сами по себе

`NpcLocoDriver283` мерил скорость в **блоках в секунду**, а сравнивал с эталоном `FULL_SPEED = 0.24`
— это **блоки в тик**. Разница в 20 раз:

```
было   0.24 (блоки/тик)                 при скорости 2 б/с вес = 2 / 0.24 = 8.3 -> всегда 1.0
       фаза = скорость * 20/0.24 = 166 юнитов/с = 8.3 юнита/тик
стало  4.317 (блоки/с, скорость игрока)  при 2 б/с вес = 0.46, фаза = 9.3 юнита/с = 0.46/тик
```

То есть вес бленда был приколот к 1.0 при любой скорости, а ноги перебирали в 8 раз быстрее, чем
нужно. Теперь фаза идёт ровно по расстоянию: 1 юнит за тик при 4.317 блока/с, меньше скорость —
медленнее шаг.

**Ожидаемое следствие:** ноги станут заметно медленнее, чем в 315. Это и есть правильная связь со
скоростью.

## 2. Один кадр сброса при переходе в idle

Смешивание поз в 315 стартовало от **своего же предыдущего сэмпла** и отключалось, если сэмпл
старше 250 мс. Первая запись после паузы в анимации применялась целиком — отсюда рывок на один
кадр при остановке.

Теперь поза **снимается до записи клипа** (`NpcPoseBlend315.capture`, хук на HEAD `Pose#set`), и
смешивание всегда идёт от реальной позы модели, даже если до этого в часть тела никто не писал.

## Что изменено

```
NpcLocoDriver283        FULL_SPEED 0.24 -> 4.317 (блоки/с), UNITS_PER_BLOCK = 20/FULL_SPEED
NpcPoseBlend315         + capture(part) и BEFORE; blend стартует от позы до записи
NpcPoseBlendMixin315    + хук на HEAD Pose#set
```

## Гейт

`tools/pursuit_check.py` теперь проверяет и единицы измерения:

```
FULL_SPEED     >= 3.5   (иначе эталон снова в блоках за тик)
UNITS_PER_BLOCK >= 3.0
capture в NpcPoseBlend315 и вызов из миксина
```
На 315 все три падают с точным диагнозом, на 316 — OK.

## Что проверить

1. Идёт медленно — ноги перебирают медленно; ускоряется — чаще. Связь видна.
2. Остановился — никакого однокадрового рывка, анимация уходит в idle плавно.
3. Разворот на месте — ноги не «шаркают» на полной скорости.
