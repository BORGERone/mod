# SettledLands 0.8.0 — Build 319 «Вставка в центр экрана»

## Что было не так

Ctrl+V ставил блок по его же координатам из буфера плюс фиксированные +24/+24:

```
копировали в графе на x=1200  ->  вставляли в другой граф  ->  ноды появлялись за пределами вида
```

Внутри того же графа это выглядело как аккуратный шаг в сторону, но при переносе в другой граф, к
другому NPC или из другого мира блок оказывался вне экрана — со стороны выглядело так, будто вставка
не сработала (статус писал «Вставлено нод: 3», а на холсте пусто).

## Что теперь

`pasteCentered` считает **рамку блока** (`bounds`: minX/minY/maxX/maxY) и сдвигает весь блок так, чтобы
его середина попала в середину **видимого холста**:

```
центр холста = canvas.worldX((left + right) / 2), canvas.worldY((top + bottom) / 2)
dx = round((центрX - серединаБлокаX) / 8) * 8      // холст двигает ноды по сетке 8
dy = round((центрY - серединаБлокаY) / 8) * 8
```

- внутренняя раскладка блока не меняется — ноды сохраняют взаимное расположение;
- сдвиг кратен 8, поэтому вставленный блок стоит на той же сетке, что и всё остальное (первое же
  перетаскивание любой ноды не «спрыгивает» на полклетки);
- если у холста ещё нет геометрии (ширина/высота нулевые), используется старый сдвиг +24;
- координаты по-прежнему подрезаются по `MAX_COORD` (±32768).

Вьюпорт берётся у холста, а не у окна: панель инспектора справа в центр не попадает.

## Что изменено


Версия, `displayName` и описание обновлены; новых классов и миксинов нет — 466 записей, как в 318.

## Гейт

`tools/clipboard_check.py` теперь проверяет и центрирование: в `ClipboardRoundTrip` добавлены

```
bounds() на скопированном блоке
pasteCentered(..., 1000, 500): середина блока попадает в 1000/500 (±8, сетка),
                               относительное смещение нод сохранено
```

Гейт компилирует тест против самого jar и запускает его без игры.

## Что проверить

1. Скопировать три ноды → перейти в другой граф (или к другому NPC) → Ctrl+V: блок появляется по центру
   видимой области.
2. Прокрутить холст/сдвинуть вид → Ctrl+V: блок снова по центру того, что видно.
3. Внутренние связи целы, вставленное выделено, Ctrl+Z снимает всю вставку одним шагом.
