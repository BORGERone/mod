# SettledLands 0.8.0 — Build 320 «Зона ноды „В радиусе“ частицами»

## Что добавлено

У ноды **«В радиусе»** появился тумблер **«Зона»** — маленький квадратик с подписью **над карточкой**
ноды (слева сверху). Включённый тумблер заставляет сервер рисовать круг, который эта нода измеряет:
кольцо частиц ровно на расстоянии `radius` вокруг NPC.

```
карточка ноды «В радиусе»
┌──────────────────────────┐
│ ☑ Зона                   │   <- новый тумблер, выше карточки, размер фиксирован при любом зуме
├──────────────────────────┤
│ В радиусе                │
│ ...                      │
└──────────────────────────┘
```

Включённый тумблер = в мире вокруг NPC видно кольцо (закрыть редактор — видно сразу).

## Где хранится флаг

У ноды нет свободного поля, поэтому тумблер использует `Node#timerRepeat` — сохраняемое **boolean**
поле, которое читает только ветка ноды «Таймер». На ноде «В радиусе» его не читает никто, зато оно:

- сохраняется в NBT вместе с графом (Ctrl+S отправляет граф целиком);
- копируется `Node.copy()`, значит переживает undo/redo;
- переносится через буфер обмена (в формате `SLGRAPH318` поле `timerRepeat` уже есть).

Один владелец флага — `NpcRadiusZone320.visible/setVisible`; ни рисование, ни обработчик клика не
трогают поле напрямую, и гейт это проверяет.

## Стоимость

```
PERIOD_TICKS  8     кольцо обновляется 2.5 раза в секунду, не каждый тик
POINTS        24    столько частиц в кольце; каждая — один sendParticles с count=1
VIEW_RANGE    48    если рядом нет игрока — не отправляется ничего
MAX_RADIUS    64    радиус кольца подрезается, сама проверка ноды не меняется
```

Сканирование графа тоже не каждый тик: всё начинается с `tickCount % 8`.

## Что изменено

```
новый NpcRadiusZone320             кольцо на сервере (sendParticles, ENCHANT, 24 точки)
новый NpcRadiusZoneUi320           квадратик и подпись на холсте, попадание по клику
новый NpcRadiusZoneMixin320        @Inject HEAD GuideNpc#customServerAiStep -> tick(npc)   [общий список]
новый NpcRadiusZoneUiMixin320      TAIL drawNode -> рисовать, HEAD mouseClicked -> переключить [клиент]
ru_ru.json / en_us.json            + gui.settledlands.graph.radius_zone ("Зона" / "Zone")
```

Клик по тумблеру забирается **до** штатной обработки мыши, поэтому он не начинает перетаскивание ноды.
Подпись локализована; размер и положение тумблера не зависят от зума, как у портов.

**На поведение ничего не влияет:** проверка радиуса, диалоги и граф работают как раньше. Если рядом
нет игрока или радиус `0` — не рисуется ничего.

## Гейт

Новый `tools/radius_zone_check.py`:

```
4 класса на месте, серверный миксин в common, клиентский — в client
границы: PERIOD_TICKS >= 2, POINTS >= 12, VIEW_RANGE >= 16, MAX_RADIUS <= 128, RING_LIFT <= 1.0
NpcRadiusZone320 читает timerRepeat (флаг переживёт сохранение), шлёт sendParticles, берёт ENCHANT
NpcRadiusZone320 не двигает NPC (setDeltaMovement запрещён — это индикатор, а не механика)
рисование читает флаг через visible(), клик пишет через setVisible()
ключ gui.settledlands.graph.radius_zone в ru_ru.json и en_us.json
```

На 319 гейт падает, на 320 — OK.

## Что проверить

1. Выделить ноду «В радиусе», щёлкнуть квадратик над карточкой — он заполняется.
2. Ctrl+S, закрыть редактор: вокруг NPC кольцо частиц радиусом из ноды.
3. Поменять радиус, Ctrl+S — кольцо меняет размер.
4. Выключить тумблер, Ctrl+S — кольцо исчезает.
5. Скопировать ноду и вставить — флаг переезжает вместе с ней.
