# SettledLands 0.8.0 — Build 322 «Провод подключается к точке перегиба»

## Что было не так

Точки перегиба из 321 были только визуальными. Если тянуть провод и отпустить его **на точке**, это
считалось отпусканием на пустом месте холста: штатный код знает только порты и ноды, поэтому
открывалось меню «вытянуть из провода ноду». Подключиться к точке было нельзя.

## Что теперь

Провод можно **отпустить на точке**, и он к ней подключится:

```
   [A] ─────┐
            ●─── [C]        A → C с изгибом через точку
   [B] ─────┘                плюс прежний B → C, который через неё уже шёл
```

Точка становится **узлом схода**: несколько проводов входят (каждый получает изгиб в этой точке),
один выходит к той же цели.

Как это делается:

1. подсчёт — при отпускании ищется точка под курсором (`handleAt`);
2. проверка (`NpcWireJoin322.canJoin`): нельзя на себя (петля), нельзя на несуществующую ноду;
3. соединение создаётся **штатным** `NpcDialogueGraph#connect(from, to, port)` — те же правила, что
   и для обычного провода (отказ, если нельзя), только после этого добавляется изгиб;
4. один шаг undo (`remember()`), затем `changed()` и статус «Соединено».

Если отпустить провод не на точке, всё работает как раньше — ничего не перехватывается.

Пока провод тянут, точка под курсором подсвечивается и увеличивается — видно, что её можно взять как
цель.

## Что изменено

```
новый NpcWireJoin322          canJoin / join: connect через граф + изгиб в точке
NpcWirePointsUi321            перегрузка drawHandles(..., dropping) и подсветка точки
NpcWirePointsMixin321         HEAD mouseReleased: сначала конец перетаскивания точки,
                              затем — отпускание провода на точке (до штатного меню)
```

## Что поведение **не** меняет

Сами точки по-прежнему ничего не пишут в поля связей: гейт проверяет, что класс хранилища не
присваивает ни `next`, ни `falseNext`, ни `choices`, ни `triggers`, ни `randomBranches`, ни
`varInputNode`. Соединение появляется только когда его создаёт **ваше** действие, и создаёт его
штатный `connect` графа — то есть диалог видит ровно то же, что если бы вы соединили ноды напрямую.

## Гейт

`tools/wire_points_check.py` дополнен:

```
NpcWireJoin322 на месте
класс соединения не присваивает поля связей напрямую (только graph.connect)
круговая проверка: join создаёт связь, изгиб появляется в точке,
  провод, на котором точка стоит, не меняется, петля и несуществующая нода отклоняются
```

## Что проверить

1. Протянуть провод от выхода ноды и отпустить **на точке** — соединение создалось, провод идёт
   через точку.
2. Пока тянешь, точка подсвечивается.
3. Отпустить провод на пустом месте — как раньше (меню), ничего не сломалось.
4. Ctrl+Z — соединение и изгиб отменяются вместе.
5. Провод, на котором стоит точка, остался тем же.
