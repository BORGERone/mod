# SettledLands 0.8.0 — Build 325 «Сколько угодно точек на проводе, в том числе на ждущем»

## Что было не так

Двойной клик по проводу искал провод по **прямой линии** между портами — по той кривой, которая
рисуется, когда точек на проводе нет. Провод, который уже уходит через точку, рядом с этой линией
не проходит, поэтому второй клик по его сегментам не находил провод. Отсюда ровно то, что вы
описали: на проводе, который ведёт к точке, новую точку поставить нельзя.

## Что теперь

Попадание по проводу считается **по тому пути, который нарисован** — по всем его точкам по порядку,
и по ждущим проводам тоже. Поэтому двойной клик всегда попадает в тот провод, который под курсором.

- **Нода — точка — нода**: двойной клик по проводу, точка появляется сразу на нём.
- **Нода — точка — точка — нода**: клик по любому сегменту ставит точку **именно на этот сегмент**,
  поэтому точки идут в том порядке, в каком вы их ставили.
- **Нода — точка — точка (ждёт)**: на проводе, который кончается точкой, тоже можно ставить точки —
  сколько угодно, они выстраиваются в том же порядке.
- Порядок сохраняется при движении и удалении: убираете среднюю — остальные остаются на месте.

```
   [A] ──●──●──●── [B]        три точки на проводе, любая тянется и удаляется
   [A] ──●──●            провод ждёт у первой точки, у него своя точка
```

Как и раньше:

| Действие | Что происходит |
|---|---|
| Двойной клик по проводу | Точка на проводе, на этом сегменте |
| Двойной клик по точке / правая кнопка | Точка удаляется |
| Тянуть точку (●) | Точка едет со всеми своими проводами |
| Тянуть из порта (▪) точки | Из точки тянется провод; отпустить на ноде — все её провода идут туда |
| Ctrl+Z | Один жест — один шаг истории |

Ничего в диалоге не меняется: точки — это только то, как провода нарисованы, а ждущий провод
по-прежнему никуда не подключён, пока вы не прицелите точку.

## Что изменено

```
NpcWirePoints321        провод теперь «маршрут» из точек: p<порт>t<цель>:x,y x,y … и
                        h<порт>@x,y x,y … (последняя — точка, где провод кончается);
                        addBend(…, index) вставляет точку в нужное место маршрута,
                        addRoutePoint — точка на ждущем проводе,
                        promote переносит весь маршрут в настоящую связь

NpcWirePointsMixin321   новый клик: точка на ждущий провод (addRoutePoint) или в нужное место
                        маршрута (addBend с индексом); ждущий провод рисуется по всем своим точкам
```

Старый текст читается: `SLP1` и ждущие провода из 323/324 (одна точка) — это маршрут из одной
точки.

## Что проверить

1. Двойной клик по проводу A→B → точка. Ещё двойной клик по сегменту A→точка → вторая точка между
   ними; ещё по сегменту точка→B → третья.
2. Двойной клик по проводу, который ведёт к точке и ждёт → появляется вторая точка на этом проводе.
3. Тянуть среднюю точку — соседние стоят на месте, порядок не путается.
4. Удалить среднюю двойным кликом — провод остаётся с двумя другими точками.
5. Потянуть из порта последней точки на ноду — все провода этой точки идут туда, все её точки
   остаются на своих местах.
6. Ctrl+Z после каждого действия.
