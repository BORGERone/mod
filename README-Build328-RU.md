# SettledLands 0.8.0 — Build 328 «Провод находит точку по двум концам»

## Что было не так

Точка хранится в узле под ключом **«номер порта : цель»**, а провод при отрисовке ищет её по
**своему** ключу. Три сборки я пытался сделать так, чтобы эти два номера совпадали. На вашем
скриншоте видно, что точка стоит ровно на проводе (это уже работает — 327 ставит её проекцией на
кривую), но провод через неё не идёт и не идёт за ней, когда вы её тащите. Значит номера не
совпадают, и точка «висит» сама по себе.

## Что теперь

Провод больше **не зависит** от совпадения номера. Если точного ключа нет, маршрут ищется **по двум
концам провода** — от какого узла к какому, в любую сторону, с любым портом. Совпадать должны только
концы, а они не могут не совпасть: провод и точку создаёт один и тот же клик.

```
   точка: узел #7, ключ «0:#9»
   провод: #7 → #9           → точный ключ пуст → ищем по концам → находим
```

## Диагностика в логе

В `latest.log` теперь есть строки с меткой `[settledlands/wires]` — не чаще двух раз в секунду и
только когда содержимое меняется:

```
[settledlands/wires] store: #7{0:9=1} #9{...}      ← что реально лежит в хранилище
[settledlands/wires] cable #7 p0 -> #9: found by ends, 1 point(s)   ← какой провод искали по концам
```

Этого достаточно, чтобы увидеть, на чьей стороне расхождение, вместо догадок.

## Что проверить

1. Двойной клик по проводу → точка на проводе, **провод изгибается через неё**.
2. Потянуть точку → провод идёт за ней.
3. Если провод по-прежнему не идёт через точку — пришлите `latest.log` (после того, как поставили
   точку и потянули её). В логе будут две строки `[settledlands/wires]`, по ним я скажу точную
   причину.

## Что изменено

```
NpcWirePoints321        routed(graph, from, to) — маршрут по двум концам, в обе стороны, любой порт;
                        dump(graph) — содержимое хранилища одной строкой; note(channel, text) — запись
                        в лог не чаще двух раз в секунду и только при изменении
NpcWirePointsMixin321   отрисовка провода: точный ключ → если пусто, поиск по концам (и строка в лог);
                        строка «что лежит в хранилище» раз в кадр (с ограничением по частоте)
```

Разметка хранения не менялась: `SLP2`, `p<порт>t<цель>:x,y …`, `h<порт>@x,y …`.
