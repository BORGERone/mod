# SettledLands 0.8.0 — Build 329 «Провод: проверка, а не догадка»

## Что было не так

По логу с 328 видно главное: **точка жива, а провод её не спрашивает**.

```
[settledlands/wires] store: #7{0:6=1 }      ← в хранилище узла #7 лежит точка: порт 0 → узел #6
[settledlands/wires] store: #7{h0=1 }       ← жест «вытянуть из порта» тоже пишет в хранилище
```

Эти строки печатает наш хук в конце `wires(...)` — значит он выполняется, точка записывается и
читается обратно. Но за все 21 строку `store:` в логе **нет ни одной** строки
`cable #7 p0 -> …: found by ends`. На экране это означает одно из двух, и **выглядит одинаково**:

- перехват `cable(...)` для этого провода **вообще не вызывается** (тогда провод рисуется штатно,
  ключ никто не спрашивает — и строки, конечно, нет);
- перехват **вызывается, но с другой целью** (не #6), тогда точный ключ пуст, а поиск по концам
  ничего не находит.

Гадать между ними — это ещё одна сборка «наугад». Поэтому 329 **ничего не меняет в поведении**:
она ставит одну строку на вход перехвата.

## Что теперь в логе

```
[settledlands/wires] cable-hit #7 p0 -> #6, points=1
```

Строка пишется **до** любой проверки точек: `from`, порт, `to` — ровно те, с которыми экран позвал
отрисовку провода, и `points` — что вернул точный ключ. Не чаще двух раз в секунду на провод и
только при изменении. Читается так:

| Что в логе | Что это значит | Куда пойдёт правка в 330 |
|---|---|---|
| строк `cable-hit` **нет вообще** | наш перехват не выполняется: провод рисует кто-то другой, либо перехват занят хуком цвета на той же инструкции | перехват переносится на другое место |
| `cable-hit #7 p0 -> #6, points=1` | перехват жив, ключ совпал — значит маршрут строится, а ломается отрисовка сегментов | правка в построении сегментов |
| `cable-hit #7 p0 -> #X, points=0` (X ≠ 6) | ключ расходится: точка записана на #6, а провод идёт на #X | правка в `wireAt`/`addBend` |
| `cable-hit #7 p0 -> #6, points=0` | перехват жив, ключ тот же, а хранилище узла в этот момент пусто | правка в чтении хранилища |

## Что проверить

1. Открыть тот же граф (`Реплика #7` → карточка `Цель: NPC`).
2. Двойной клик по проводу — поставить точку, **потянуть её в сторону**.
3. Прислать `latest.log`. Ничего специально искать не нужно — строки с меткой
   `[settledlands/wires]` есть всегда.

Поведение то же, что в 328: точка ставится на провод, тащится, удаляется; провод по-прежнему не
изгибается — это и есть предмет следующей сборки, а не этой.
