# SettledLands 0.8.0 — Build 331 «Точка удаляется средней кнопкой мыши»

## Что было не так

Точка снималась двойным кликом и правой кнопкой. Средняя кнопка не делала ничего: решение о клике
знало только ЛКМ и ПКМ, поэтому СКМ по точке проваливалась в штатный экран.

## Что теперь

СКМ по точке или по её порту снимает точку — ровно тем же действием, что и ПКМ. Один жест — одно
действие, один Ctrl+Z откатывает его целиком.

```
ЛКМ        — взять точку / вытянуть провод из порта (одиночное нажатие)
двойной ЛКМ на проводе — поставить точку
ПКМ        — снять точку (по точке или по порту)
СКМ        — снять точку (по точке или по порту)   ← эта сборка
```

## Что проверено

- `wire_points_check` (в него входит `ClickOrder`) — порядок жестов закреплён тестом: СКМ по точке и
  по порту = удаление, СКМ по пустому месту = ничего. Тест обновлён под новое правило.
- `verify_jar` PASS, миксины, dangling refs, blue/pursuit/clipboard/radius — OK.
