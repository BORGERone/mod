# SettledLands 0.8.0 — Build 336 «Случайная реплика»**

## Что сделано

У ноды **«Реплика»** появился тумблер **🎲 Случайная реплика** — прямо над карточкой ноды на холсте.

- Включил тумблер → **бросок костей** по числу фраз в ноде, результат **записывается в саму ноду**.
- Фразы разделяются **новой строкой** (Enter в поле текста). Пустые строки фразами не считаются.
- Дальше нода **всегда** говорит выпавшую фразу: выпало 3 из 5 — значит третья строка, и так до
  следующего броска. Ничего не перебрасывается «на каждый диалог».
- Надпись на тумблере показывает, что выпало: `🎲 Строка 2 из 5`.
- Выключил и включил заново — новый бросок. Правка текста бросок **не** меняет: пока выпавшая строка
  существует, нода продолжает говорить её.
- Пропала строка (сократил текст) — номер подрезается к последней существующей, нода не молчит.
- Плейсхолдеры (`{player}`, отношение, очки) подставляются **в выбранной фразе**, как обычно.

## Где это живёт

```
NpcRandomLine336              правило: фразы, бросок, выбор; что считать строкой и как подрезать
NpcRandomLineNodeMixin336     Node#lineFor — единственная точка, через которую диалог берёт текст
                              ноды; если тумблер включён, отдаётся выпавшая фраза
NpcRandomLineUi336            сам тумблер: рисуется над карточкой, размер в экранных пикселях,
                              поэтому читается на любом зуме
NpcRandomLineUiMixin336       drawNode (TAIL) — рисуем поверх карточки
                              mouseClicked (HEAD) — клик забираем до перетаскивания ноды
```

Флаг и результат броска хранятся **в одном сохранённом поле ноды** — `varValue`: `0` = выключено,
`1..n` = включено и выпавшая фраза. Это поле читают только ноды «Переменная» и «Если», на «Реплике»
оно свободно, его по умолчанию `0`, и оно уже проходит через save/load, копирование ноды, отмену
(Ctrl+Z) и буфер обмена. Новых полей и нового NBT не появилось — старые миры открываются как есть,
у всех «Реплик» тумблер по умолчанию **выключен**.

## Чего это не делает

- Не трогает **варианты по отношению**: если у ноды они есть и тумблер включён, побеждает случайная
  фраза из основного текста (варианты — это про отношение, случайная реплика — про содержание).
- Не трогает «Реплику отъезда/прибытия» (спец-реплики распорядка) — только обычные реплики.
- Не перебрасывает кости на сервере: бросок один раз, в момент включения тумблера.

## Что проверить

1. Взять ноду **«Реплика»**, написать в текст 3 фразы, каждую с новой строки.
2. Нажать **🎲 Случайная реплика** над карточкой → надпись стала `🎲 Строка N из 3`.
3. Сохранить (Ctrl+S), подойти к NPC, довести диалог до этой реплики → он говорит **ровно одну**
   фразу, ту, что в надписи.
4. Перезайти в мир → нода говорит **ту же** фразу (бросок сохранился).
5. Выключить и включить тумблер → номер сменился (новый бросок).
6. Сократить текст до 2 фраз при «Строка 3 из 3» → нода говорит вторую, не молчит.
