# SettledLands 0.8.0 — Build 345 «Урон по источнику + кубики у каждого NPC»

В этой сборке — 344 (руки и ноги Cinematic) плюс две правки графа. Один полный джарник.

## 1. Почему нода «Урон» не срабатывала

Это мой баг, не твой.

В инспекторе «Источник урона» и на карточке ноды варианты пронумерованы так:

```
0 — Любой урон (Any)   1 — От игрока (Player)   2 — От монстра (Monster)   3 — Не от игрока
```

и нода хранит **номер строки**. А обработчик урона (`GuideDialogue.matchesDamageFilter`) читал тот же
номер в **другом порядке**:

```
0 — игрок   1 — монстр   2 — не игрок   3 — любой
```

То есть твоя нода с «От игрока» (номер 1) проверялась как «от монстра». Удар игрока по НПС никогда не
совпадал — и до действия дело не доходило вообще: ни хила, ни команды, ни строки в логе. У «Любого
урона» была обратная беда: он срабатывал только на игрока.

**Что сделано:** обработчик теперь отвечает по правилу «как на экране» — 0 любой, 1 от игрока, 2 от
монстра, 3 не от игрока. Это одна точка (`matchesDamageFilter`), через неё же работает и нода-значение
«Урон», так что обе теперь совпадают с выпадающим списком.

**Важно про цель команды.** Строка действия выполняется от **игрока** (того, кто бьёт), поэтому `@p` —
это игрок, а не НПС. Чтобы лечить НПС, в моде есть токен `@npc` (подставляется uuid НПС, это проверено
ещё в 292–293):

```
effect give @npc minecraft:instant_health 1 100
```

## 2. Случайная реплика — бросок у каждого NPC свой

Было: результат броска хранился в самой ноде, то есть **один на весь мир** — все НПС с этой нодой
говорили одну и ту же фразу, потому что читали одно и то же число.

Стало: кубики у каждого NPC свои. Тело бросает один раз, когда ему впервые нужна эта реплика, и
запоминает свой вариант — пока НПС существует, он говорит именно его; следующий НПС (или он же после
перезагрузки мира) бросает заново. Кэш слабый по НПС: тело ушло — его броски ушли вместе с ним, мусор
не копится. В ноде по-прежнему остаётся твой «пример» (он виден в инспекторе и на карточке), но на
речь других НПС он больше не влияет.

Тумблер и его смысл не менялись: выключен — нода просто говорит свой текст.

## Что проверить

1. Игра запускается.
2. Нода «Урон» с «От игрока (Player)», мин. урон 1, откат 1с, действие
   `effect give @npc minecraft:instant_health 1 100` → ударь НПС: он лечится, в `latest.log` есть
   `НПС <имя>: выполнена команда триггера: «/effect give …»`.
3. Смени источник на «От монстра» → удар игрока её больше не поднимает.
4. «Любой урон» → срабатывает на любой урон, а не только на игрока.
5. Реплика с рандомом: два НПС с этой нодой говорят **разные** фразы (в логе при первом броске —
   `[SettledLands/NpcRandomLine345] random line: NPC '<имя>' rolled 2 for node 7`).
6. Костёр и верстак (344): ноги и руки Айви на месте.
