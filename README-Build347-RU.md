# SettledLands 0.8.0 — Build 347 «Нода урона в личной вкладке снова работает»

Причина найдена по трассировке 346 — за один удар.

## Что показал лог

```
[dmg] hit npc='Проводник' amount=1.0 source=entity=ServerPlayer … own=enabled=true entry=0 nodes=5 damage=1
[dmg]   node #4 type=6 min=1 filter=0(any) cooldown=1s if-in=0 -> gate-ok
[dmg] chain npc='Проводник' graph=enabled=false entry=-1 nodes=2 damage=0 …   (три раза)
```

Твоя нода **есть** на сервере: в личной вкладке 5 узлов, из них **один** — «Урон» #4, и все её условия
проходят. Но цепочка её не читала: все три вызова, которые доходят до обработки урона, несут **другой
граф** — 2 узла, `enabled=false`, `entry=-1`, нод урона **ноль**. Это «Общее».

## Почему

334-я сделала «Общее» общим и подменила им личные вкладки — но сделала это через хук на
`GuideDialogue.handleNpcDamaged`, а через этот **один** метод проходят **все три** штатные цепочки:
личная вкладка, «Распорядок»/прогулка и анимация. Один пустой или недописанный общий граф выключал
ноды урона сразу во всех трёх — молча и у всех NPC.

## Что сделано

Урон из «Общего» больше **не подменяет** личные вкладки, а добавляется к ним:

* хук 334 снят (`NpcCommonGraphDamageMixin334` удалён из джарника и из списка миксинов);
* новый `NpcCommonGraphDamageMixin347` вешается на `GuideNpc.hurt` (HEAD) и один раз за удар
  прогоняет цепочку урона общего графа — рядом с тремя штатными, которые теперь идут как раньше;
* ничего не отменяется, личная вкладка читается **всегда**, «Общее» — дополнительно, если в нём есть
  ноды урона. Пустой общий граф стоит одного прохода по двум узлам.

Нода урона теперь срабатывает в любой из четырёх вкладок, включая твою «Главный» #4.

Трассировка из 346 осталась (до 80 строк за сессию, потом сама выключается) — по ней видно, что вышло.

## Что проверить

1. Игра запускается, диалог, рандом-реплики и руки/ноги на месте.
2. Ударь НПС с нодой «Урон» из личной вкладки (`От игрока`, мин. 1, откат 1с,
   `effect give @npc minecraft:instant_health 1 100`) — НПС лечится.
3. В логе по удару теперь должно быть четыре строки `[dmg] chain` (личная, прогулка, анимация, общее)
   и по твоей ноде `-> MATCH`, затем
   `НПС Проводник: выполнена команда триггера: «/effect give …»`.
4. Если нода лежит в «Общем» — она тоже срабатывает.

Отдельно, не про нас: в прошлом логе HackersAndSlashers 2.0-beta2.5 падал с NPE
(`PlayerHelper.lastComboStep()`), из-за чего урон по НПС не начислялся вообще. На срабатывание ноды это
не влияет, но «хп не меняется» будет выглядеть так же, пока этот мод не обновлён.
