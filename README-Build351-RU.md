# SettledLands 0.8.0 — Build 351 «Триггер блоков»

Блок теперь умеет носить граф: ПКМ жезлом — настройка, ПКМ пустой рукой — запуск.

## Что сделано

1. **ПКМ жезлом настройки НПС по блоку** — открывается граф этого блока. Открывается **штатный
   редактор** НПС: то же полотно, те же провода, отмена/повтор, копирование, инспектор. Ничего не
   перерисовывалось и не переизобреталось — экран получил профиль, главный граф которого и есть граф
   блока, и id из своего диапазона. Сохранение идёт тем же пакетом, что и у НПС, сервер по id
   понимает, что это блок.
2. **Граф живёт в данных мира**, а не в сущности: файл `settledlands_block_triggers`, ключ —
   измерение + координаты. Сломал блок и поставил новый на то же место — граф на месте. Поставил
   второй такой же блок рядом — у него свой граф.
3. **ПКМ пустой рукой по блоку** запускает цепочку с начальной ноды. Нет начальной ноды — не
   происходит ничего, как ты и просил. Блок при этом делает и своё штатное действие: граф — добавка,
   а не замена.
4. **Палитра блока — четыре ноды**, те, которые блок реально может исполнить:
   * **Триггер** — действия/команды; команда выполняется от лица игрока, который кликнул, то есть
     `@p` — это он;
   * **Условие If** — сравнение переменной (своей или подключённой синим проводом), как у НПС;
   * **Переменная** — та же именованная переменная (`NpcPoints`), что у НПС, так что блок и НПС могут
     считать один счётчик;
   * **Случайность** — выбор ветки.

   Остальные строки палитры (реплика, кнопка, квест, анимация, движение, маршрут, катсцена, проверка,
   урон, время, таймер) на клик отвечают строкой «У блока доступны: Триггер, Условие If, Переменная,
   Случайность». Не молчат: у блока нет тела, чтобы говорить и ходить, и нет события, чтобы ловить
   урон или тикать — обещать это палитрой было бы враньём.
5. Вкладка у блока одна — главная. Вторая и третья вкладки (распорядок/общее) у блока не сохраняются
   и не исполняются, поэтому не открываются, а не «сохраняются в никуда».

## Что проверить

1. ПКМ жезлом по блоку (любому: сундук, печь, камень) — открылся редактор, в нём пусто, статус
   «Граф блока · x y z».
2. Положи **Триггер**, впиши команду (например `/say привет` или `effect give @p minecraft:speed 5 1`),
   ПКМ по ноде → «Сделать начальной репликой» (появится метка «НАЧАЛО»), **Сохранить**, закрыть.
3. ПКМ пустой рукой по этому блоку — команда выполнилась. `@p` — это ты.
4. Добавь **Условие If** и **Переменную**, проверь ветвление.
5. Перезайди в мир — граф на месте, ПКМ снова работает. Сломай блок и поставь на то же место —
   граф остался.
6. Клик по строке палитры, которой у блока нет (например «Реплика») — строка-подсказка, нода не
   создаётся.
7. ПКМ с предметом в руке по блоку — граф **не** запускается (жезлом — настройка, пустой рукой —
   запуск, с предметом — ничего).

## Чего здесь нет и почему

* **Время, таймер, проверка, урон** для блока: блока не касается урон, он не тикает и у него нет
  «радиуса обзора». Чтобы они работали, нужен тикер по блокам — отдельная сборка, если понадобится.
* **Реплики/квесты/анимации/движение/катсцена** у блока: их исполняет тело НПС, у блока тела нет.
* Граф не удаляется кнопкой: чтобы обнулить — открой блок и сохрани пустой граф; лимит
  `4096` блоков с графом, при переполнении сохранение честно отвечает отказом в чат.

## Технические заметки

* Новых внешних вызовов Minecraft/NeoForge — **ноль**: всё, что вызывает новый код, уже вызывается
  базовым jar (гейт 3 проверяет это против 350).
* Правый клик приходит по одному на руку, поэтому один физический клик обрабатывается один раз на
  тик и блок; быстрый второй клик в следующем тике проходит.
* Ни одного нового тика, ни одной работы на кадр: открытие — поиск в мапе, запуск — обход цепочки с
  ограничением 256 нод и множеством посещённых.
