# SettledLands 0.8.0 — Build 355 «Тумблер и удаление графа»

Две правки: тумблер «Видимость» срабатывает сразу, и у блока появилась кнопка удаления графа.

## Что было не так

**Тумблер не выключал кольцо.** Кольцо рисует **сервер** — по тому графу, который у него сохранён.
Строка «Видимость» меняла флаг только в редакторе, а на сервер граф уходил лишь по кнопке
«Сохранить» (или при закрытии редактора с сохранением). В итоге тумблер выглядел выключенным, а
кольцо оставалось: два состояния расходились, и понять, какое из них настоящее, было нельзя.

## Что сделано

1. **Тумблер применяется по клику.** Строка «Видимость радиуса: да/нет» сразу после переключения
   **сохраняет граф**, поэтому сервер узнаёт о флаге в тот же момент и кольцо гаснет/появляется
   мгновенно. Ничего запоминать и нажимать «Сохранить» больше не нужно.
2. **Кнопка «Удалить граф»** в верхней панели редактора блока (рядом с отменой/повтором), только для
   блока — у НПС этой кнопки нет.
   * **В два клика**: первый — кнопка меняется на «Нажми ещё раз», второй (в течение 5 секунд) —
     удаляет. Случайно не нажмёшь.
   * Удаляет: очищает все ноды, сбрасывает стартовую ноду и сохраняет. Сервер в ответ **удаляет запись
     блока целиком** — подсветка гаснет, ПКМ пустой рукой больше ничего не запускает, то есть блок
     становится таким же, как будто его никогда не настраивали.
   * Пустой граф теперь и означает «графа нет» (раньше оставалась пустая запись, и блок продолжал
     искрить). Если граф уже пуст, кнопка неактивна.
   * В чат приходит подтверждение: «Граф блока удалён · x y z».

## Что проверить

1. Открой блок жезлом, выбери ноду «В радиусе», нажми «Видимость радиуса: да» — кольцо появилось
   **сразу**. Нажми ещё раз — кольцо **сразу** пропало. Сохранять не надо.
2. То же у НПС: строка в инспекторе ноды «В радиусе» у НПС — включил/выключил, кольцо вокруг НПС
   появляется и исчезает сразу.
3. Открой блок с графом — в верхней панели кнопка «Удалить граф». Первый клик — «Нажми ещё раз»,
   второй — граф исчез, в чат пришло «Граф блока удалён».
4. Убери жезл, возьми снова — удалённый блок больше не искрит. ПКМ пустой рукой — ничего не
   происходит. ПКМ жезлом — открывается пустой редактор.
5. Зайди в мир заново — блок остался без графа.

## Технические заметки

* Новых обращений к Minecraft/NeoForge — **ноль** против 354.
* Обе кнопки — обычные виджеты того же экрана, никакой новой отрисовки и ни одной работы на кадр.
* Удаление не трогает чужие данные: правится только граф блока, запись удаляется из world-данных
  (`settledlands_block_triggers`), соседние блоки не задеваются.
* Ошибка в любом пути по-прежнему сообщается одной строкой и не роняет сервер.
