# SettledLands 0.8.0 — Build 357 «Реплика у блока»

У блока появилась нода **«Реплика»** — блок говорит текст игроку, который его запустил.

## Как это работает

* В палитре блока (правый клик по пустому месту на холсте) теперь **шесть** нод:
  **Реплика, Триггер, Условие If, Переменная, Случайность, В радиусе**.
* «Реплика» — та же нода-строка, что у НПС (тип 0). Поэтому всё остальное работает без нового кода:
  в инспекторе у неё обычное поле текста (то же, что у НПС), карточка на холсте рисует текст,
  сохранение и загрузка, копирование и вставка — штатные.
* **Куда говорит:** в чат игроку, который запустил цепочку (ПКМ пустой рукой, либо игрок, попавший в
  радиус ноды «В радиусе»). У блока нет тела, поэтому окна диалога нет — чат и есть его голос.
  Цепочка идёт дальше **сразу**, ждать клика не нужно.
* **Подстановки** — штатные: `%player%` → имя игрока, `%relation%` → 0 (у блока нет отношений).
* Если текст пустой или игрока нет (радиус сработал на моба) — сообщение не отправляется, но цепочка
  продолжается: пустая реплика это реплика, а не остановка.

## Что проверить в игре

1. ПКМ жезлом по блоку → правый клик по пустому месту холста → в палитре есть **«Реплика»**.
2. Поставь «Реплику», напиши текст (например `Привет, %player%!`), кнопкой «Вход» сделай её стартовой.
3. Сохрани, закрой редактор, ПКМ пустой рукой по блоку → в чате твоё сообщение с подставленным ником.
4. Соедини «Реплику» с «Триггером» (например `/say привет`) — сначала реплика, потом команда.
5. Перезайди в мир: текст и вся цепочка на месте.

## Технические заметки

* Новых обращений к Minecraft/NeoForge — **ноль** против 356 (1392 внешние ссылки, те же).
* Новых классов нет: правились `BlockTrigger351` и `NpcBlockGraph351Mixin`.
* Карта «строка палитры → тип ноды» переехала в `BlockTrigger351#typeForRow`, рядом с `PALETTE`;
  хук экрана её только спрашивает. Поэтому карту можно проверить прогоном
  (`tools/harness/BlockPaletteProbe.java`), а не чтением байткода.
* Подпись палитры (`gui.settledlands.block.palette`) обновлена в обоих языках — список нод не врёт.
* Ошибка в любом пути по-прежнему сообщается одной строкой и не роняет сервер.
