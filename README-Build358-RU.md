# SettledLands 0.8.0 — Build 358 «Окно диалога у блока»

«Реплика» блока теперь **открывает настоящее окно диалога** — то самое, что открывает НПС, — и
**камера смотрит на блок**, пока окно открыто. Чат из сборки 357 остался только запасным путём.

## Что изменилось против 357

В 357 блок говорил реплику строкой в чате и цепочка шла дальше сразу. Это было неправильно: окно
диалога — не тело НПС. Окну нужны id, строка и стиль, а тело используется только для одного —
повернуть камеру. Поэтому:

* окно открывается под **id блока** (тот же диапазон, что у редактора графа), так что клиент не
  путает блок с сущностью;
* **камера поворачивается на блок** до появления окна: сервер посылает координаты блока одним
  пакетом впереди окна, клиент считает углы той же арифметикой, что экран диалога для тела;
* **обзор мышью заблокирован**, пока окно открыто, — вид остаётся на блоке;
* **цепочка ждёт игрока**: ЛКМ / E / Enter идут дальше по ноде после реплики, **Esc** обрывает
  цепочку;
* чат остался **только запасным путём** — когда окно показать нельзя (нет игрока, пустой текст,
  недоступный стиль). Реплика не теряется никогда.

## Что проверить в игре

1. ПКМ жезлом по блоку → в графе стоит «Реплика» с текстом, кнопкой «Вход» она сделана стартовой.
2. Сохрани, закрой редактор, **ПКМ пустой рукой** по блоку.
   → Открывается **окно диалога** (как у НПС), и **камера повёрнута на блок**: блок виден в кадре.
3. Нажми ЛКМ / E / Enter → окно закрывается и цепочка идёт дальше по ноде после реплики.
4. Проверь Esc: открой окно снова и нажми Esc → окно закрывается, **цепочка не идёт дальше**.
5. Проверь, что обзор мышью заблокирован, пока окно открыто, и что после закрытия мышь снова
   работает.
6. Проверь цепочку «Реплика → Реплика»: после клика в первом окне открывается второе, и так до
   конца — без зацикливания.
7. Проверь, что окно говорит твой текст с подстановкой `%player%`.

## Технические заметки

* Новых обращений к Minecraft/NeoForge — **ноль** против 357: 1392 внешние ссылки, те же самые.
* Заменены три класса: `BlockTrigger351` (ветка «Реплики» открывает окно и останавливает цепочку,
  чат — только фолбэк), `RadiusPass354` (узел радиуса передаёт цепочке блок, на котором живёт),
  `NpcBlockOpen351Mixin` (вид конфига блока с координатами — это разговор, без них — редактор).
* Добавлено шесть: `BlockTalk358` (+`$Where`, `$Open`), `client/BlockTalkClient358`,
  `mixin/BlockTalkPick358Mixin`, `mixin/BlockTalkStop358Mixin`.
* Стиль окна берётся **у самого `GuideDialogue#style`** — рефлексией, один раз, с фолбэком в чат при
  неудаче. Собирать 26 полей `DlgStyle` руками не надо: порядок аргументов там слишком легко
  перепутать, а цена ошибки — падение клиента. Урок 342 (интерфейсный `@Invoker` для класса-цели
  Mixin не принимает) учтён: никакого `@Invoker`.
* Клик и Esc перехвачены на сервере в `GuideDialogue#pick` / `#stop`: обе точки уже отвечают «нет
  сессии — ничего не делаю», поэтому чужой id проходит мимо.
* Окно забывается через 2 минуты (и не больше 64 открытых), чтобы поздний клик не пошёл по цепочке,
  от которой игрок уже ушёл.
* Пока окно открыто, движение и обзор заблокированы — как в диалоге с НПС. Esc отпускает.
* Для проверки прицела в стубах добавлены `Entity#getEyeY/setYRot/setXRot/yRotO/xRotO` и поля
  `Minecraft#player`/`#keyboardHandler` — дескрипторы сняты с байткода самого `GuideDialogueScreen#face`,
  поэтому в игре это те же методы; на поставку стубы не влияют.

## Что пока не подтверждено в игре

* Окно у блока и прицел — проверять по списку выше (это первая сборка с окном).
* С 357 висит непроверенным: индексы строк меню создания (`PALETTE_ROWS = {0,2,3,4,5,13}`) берутся
  как **0-базовые**; если «Реплика» окажется не в той строке — скажи, поправлю на 1-базовые.
