# SettledLands 0.8.0 — Build 360 «Имя блока + без вкладок» (замена 359)

**Сборка 359 отозвана: она валила клиент при открытии любого графа.** Причина найдена и исправлена,
карточка «ИМЯ» осталась как была. Плюс у графа блока больше нет вкладок.

## Что было сломано в 359

```
Caused by: InvalidMixinException: @Shadow method addRenderableWidget in
BlockNameInspector359Mixin was not located in the target class
dev.settledlands.npc.client.NpcDialogueGraphScreen. No refMap loaded.
```

Строка инспектора с выпадающим списком цвета регистрировала свой виджет через `@Shadow` на
`addRenderableWidget`. Метод **наследуется** от `Screen`, а Mixin ищет `@Shadow` только в самом
классе-цели — не в родителях. Подменить взгляд Mixin нельзя, поэтому падала загрузка
`NpcDialogueGraphScreen`, то есть **любой** граф: и НПС, и блока.

Теперь виджет регистрируется **вызовом**, а не тенью: `Screen#addRenderableWidget` объявлен в наших
стубах, вызов компилируется ровно в тот же байткод, что делает штатное `textBox` мода (тот же
дескриптор, тот же владелец). Гейт `check_mixin_class` теперь **ловит именно эту ошибку**: на
починенном jar он зелёный, а на опубликованном 359 — падает с тем же текстом, что в логе игры, так
что такую сборку больше не выпустить.

## Что изменилось против 358 (и осталось от 359)

* у блока есть **своя карточка «ИМЯ»**: поле имени + выпадающий список цвета (белый, кремовый,
  золотой, серый). Устроена как карточка характеристик у тела: есть сразу при открытии блока, из
  палитры не добавляется, правится в инспекторе;
* окно диалога говорит **именем блока** в выбранном цвете, координаты — в подписи; безымянный блок
  говорит координатами, как в 358;
* карточек **«Характеристики»** и **«Автономный ИИ»** на графе блока нет (карточка характеристик из
  старого сейва выбрасывается при сохранении).

## Новое в 360: у графа блока нет вкладок

Вкладки НПС (`Диалог` / `Ходьба` / `Анимация`) у блока только мешали: у блока один граф, две
оставшиеся вкладки всегда пустые, а клик по ним отвечал отказом в строке статуса. Теперь у блока
**обе лишние вкладки просто не рисуются**. Это не «спрятать кнопку»: полоса вкладок — три обычные
штатные кнопки в `widgets()`, и для блочного id хук перехватывает создание кнопки с меткой вкладки,
оставляя её невидимой и некликабельной. Запрет на `switchTab` для блока остался (горячей клавишей в
пустой граф не попасть). У НПС всё как было — три вкладки на месте.

## Что проверить в игре (по порядку)

1. **Открой граф НПС** (жезл по НПС → «Диалог»). → Экран открывается, **вылета нет**. Вкладки
   «Диалог / Ходьба / Анимация» на месте.
2. **Открой граф блока** (ПКМ жезлом по блоку). → Экран открывается, **вкладок нет вообще**, а рядом
   с первой нодой стоит карточка **«ИМЯ»**.
3. Убедись, что карточек «Характеристики» и «Автономный ИИ» на канвасе блока нет.
4. Выдели карточку «ИМЯ» → в инспекторе строки **«Имя в диалогах»** (поле) и **«Цвет имени»**
   (выпадающий список). Впиши имя, выбери цвет → карточка перекрашивается на месте.
5. Сохрани, закрой, **ПКМ пустой рукой** по блоку → окно диалога с твоим именем в выбранном цвете,
   ниже координаты блока.
6. Сотри имя, сохрани, ПКМ → окно снова говорит координатами.
7. Проверь, что в инспекторе ничего не «съехало»: строки имени и цвета — внизу панели, прокрутка
   работает.
8. Мышью по тому месту, где у НПС вкладки: у блока там **пусто** и клик ничего не делает.

## Технические заметки

* База — **358**, а не 359: сборка 359 не выпускается, её классы заменены починенными.
* Заменены: `BlockTrigger351`, `BlockTalk358` (+`$Where`, `$Open`). Добавлены: `BlockName359`,
  `client/BlockNameCard359`, `BlockNameDraw359Mixin`, `BlockNameInspector359Mixin`,
  `BlockNoStats359Mixin`, `BlockNoAi359Mixin`, `BlockNameOne359Mixin`, `BlockNoTabs360Mixin`.
* Новых обращений к Minecraft/NeoForge — **ноль** против 358 (1394 ссылки, 0 новых): для скрытия
  вкладок использованы только те члены, которые мод уже вызывает (`Button#visible/active`,
  `button(...)`, `entityId()`).
* Полоса вкладок — три штатные кнопки в `widgets()`; хук `@Redirect` на `button(...)` гасит
  **только** метки `gui.settledlands.graph.tab_*` и **только** для блочного id, остальные кнопки
  (undo/redo, сохранение) идут прежним путём.
* Данные имени — в уже сохраняемых полях ноды: `Node#text` (имя, кап 32) и `Node#varValue`
  (индекс цвета 0..3 из `GuideDialogueScreen.NAME_COLORS`). Нода типа 18.

## Что пока не подтверждено в игре

* Всё по списку выше: что экран открывается без вылета, что вкладок у блока нет и что они остались у
  НПС, вид карточки и строк инспектора, поведение выпадающего списка.
* С 357 висит: `PALETTE_ROWS = {0,2,3,4,5,13}` взяты как **0-базовые** — если «Реплика» окажется не в
  той строке меню создания, скажи, поправлю.
