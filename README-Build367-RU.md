# Settled Lands — сборка 367 (zone-default)

Файл мода: `settledlands-0.8.0-build367-zone-default.jar`
Версия в игре: `0.8.0-build367-zone-default`
Собрано из базы: `settledlands-0.8.0-build366-menu-fix.jar`

## Что исправлено

**1. Полоса прокрутки была инвертирована.** Причина: я передавал колесо как `scrollY > 0 ? +1 : -1`,
а штатный экран — наоборот, `scrollY > 0 ? -1 : +1`. Поэтому прокрутка вверх двигала список вниз, и
полоса «читалась» наоборот. Теперь направление живёт в одной функции `BlockMenu363.wheelStep`, клик по
полосе идёт через тот же `scroll(int)`, и проба фиксирует знак (`up=-1 down=1 none=0`), чтобы это
нельзя было перевернуть незаметно.

**2. У нод с радиусом зона по умолчанию выключена.** Флаг тумблера — это `Node#timerRepeat`, штатное
поле ноды, и его собственное значение по умолчанию **true**. Поэтому каждая новая «В радиусе» и
каждая «Цель» появлялись уже с нарисованным кольцом частиц, хотя автор его не включал.

Теперь правило одно и в одном месте — `RadiusPass354.hideByDefault(node)` (рядом с `visible` /
`setVisible`, которые читают и пишут тот же флаг), а применяет его новый миксин
`RadiusDefault367Mixin` на `NpcDialogueGraph#add` — то есть на **любую** ноду, которую создаёт граф:
и в графе NPC, и в графе блока, и при вставке из буфера. Касается только двух типов нод, у которых
есть радиус (CHECK «В радиусе» и RADIUS «Цель»); Таймер, Реплика и остальные не тронуты.

Важно: **нода, сохранённая включённой, кольцо сохраняет** — это значение по умолчанию для новых нод,
а не стирание старых.

## Что осталось как было

Всё из 366: штатная панель меню на пять строк с полосой прокрутки, цвета строк по типу ноды, клик
достаёт до любой из одиннадцати строк. Всё из 365: Кнопка, Время, Таймер, Катсцена, Цель работают.

## Не подтверждено в игре

Проверки: 21 гейт зелёный, `verify_jar --base 366` PASS (0 удалённых членов), `validate_jar` OK.
Гейт `radius_zone_check` теперь **требует** правило «выключено по умолчанию» и прогоняет пробу
(новая нода с радиусом — выключена; таймер и реплика не тронуты; сохранённая включённой остаётся
включённой), а гейт меню **требует** `wheelStep`.

Смотреть в игре: колесо в меню листает «в ту же сторону, что рука», полоса едет вместе со списком;
у новой «В радиусе»/«Цели» кольца нет, пока не включишь тумблер.
