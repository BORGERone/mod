# Settled Lands — сборка 389 (у карточки двери два выхода: «Импульс» и синяя «Цель»)

Файл мода: `settledlands-0.8.0-build389-door-signal-target.jar`
Версия в игре: `0.8.0-build389-door-signal-target`
Собрано из базы: `settledlands-0.8.0-build388-door-stock-nodes.jar`

## Что просил

«Сделай теперь из ноды "дверь" один выходной узел сигнала и синий узел цели. Узел сигнала будет давать
импульс если дверь взломать, синий будет передавать ссылку на того кто взломал дверь.»

## Что теперь

**Новая дверь сразу нарисована так, как ты описал:** карточка двери → **«Импульс»** → **«Цель»**,
соединённые слева направо.

**«Импульс»** (янтарный) — выход двери:

* даёт импульс **только когда дверь взломали**, то есть когда собрана панель взлома;
* обычный клик по незапертой двери импульса **не даёт** (это не взлом);
* цепочка уходит из его выхода дальше — тем же интерпретатором, что у блока, со всеми штатными нодами
  из 388-й;
* у двери может быть несколько «Импульсов» — срабатывает каждый.

**«Цель»** (синяя) — ссылка на взломщика:

* в неё **пишется ник** того, кто взломал дверь; он виден на карточке («Последний: <ник>») и в
  инспекторе, и **сохраняется вместе с графом** (значит, переживает перезаход в мир);
* цепочка, выходящая из «Цели», выполняется **от имени этого игрока** — поэтому `%player%` в любом
  «Триггере» или «Реплике» после неё это именно взломщик.

Обе ноды добавлены **в конец меню создания** двери (меню блока не тронуто), поэтому их можно создать
сколько угодно раз и в любом месте графа. Всё остальное — по-прежнему штатный набор нод из 388-й.

## Что проверить

1. Открой граф двери, которую ещё не открывал → на канвасе карточка, «Импульс» и синяя «Цель», соединённые
   линиями.
2. Тумблер «Закрыта» → взломай панель → в «Цели» появился твой ник («Последний: …»).
3. Поставь после «Импульса» «Триггер» с командой `say Взломал %player%` → при взломе в чате твой ник.
4. Сделай дверь «Открыта» и просто кликни по ней → импульса нет, ник в «Цели» не меняется.
5. Перезайди в мир → ник в «Цели» на месте.
6. Удали «Цель» из графа, открой граф заново → она **не вернётся** (автосборка идёт только у новой двери).

## Честно о непроверенном и о границах

Игру я не запускаю — проверено байткодом и гейтами. **Глазами не видел**:

* как выглядят карточки «Импульс» и «Цель» (4 и 3 строки в тех же 100 px, шаг 18 px — если строка
  обрежется, скажи, сокращу текст);
* что автосборка «карточка → импульс → цель» не налезает на уже стоящие ноды у двери, которую открывали
  в 388-й (у старой двери ноды **не добавляются**, автосборка только у новой);
* что «Цель» действительно обновляется на клиенте, если редактор в этот момент открыт (граф сохраняется на
  сервере; при повторном открытии ник на месте).

Границы:

* **Импульс — только взлом.** Клик по незапертой двери граф не запускает. Если хочешь, чтобы импульс был и
  на обычное открытие, скажи — это одна строка.
* **Старые графы (388-я и раньше)** не получают «Импульс» автоматически: у них цепочка по-прежнему
  запускается с «Начала» при взломе. Ноды можно добавить из меню.
* **Ноды-события** («В радиусе», «Время», «Таймер», «Цель» из штатного набора) по-прежнему запускаются
  штатным тик-проходом, шаг цепочки их проходит — как и в графе блока.
* **Имя говорящего** у «Реплики» в графе двери всё ещё пустое (штатный код берёт его из карточки «Имя»,
  которой у двери нет) — это я предлагал сделать отдельной сборкой.
