# Settled Lands — Сборка 424 (`teleport`)

Сборка добавляет новый узел **«Телепорт»** во все редакторы графов:

- Граф НИП (включая вкладки диалога, ходьбы и анимаций);
- Граф блока-триггера;
- Граф двери;
- Граф сундука.

## Как пользоваться

1. Откройте любой граф и нажмите ПКМ по пустому полю (или потяните провод в пустоту).
2. В меню создания выберите **«+ Телепорт»** (в общем меню НИП — прокрутка вниз до конца списка; в меню блока/двери/сундука — внизу списка).
3. Выделите карточку **«Телепорт»**:
   - **Мир** — выпадающий список:
     - `Обычный мир` (`minecraft:overworld`)
     - `Незер` (`minecraft:the_nether`)
     - `Край` (`minecraft:the_end`)
     - `Чистилище` (`settledlands:purgatory`)
   - **X / Y / Z** — поля ввода координат (допускаются целые, дробные через `.` или `,`, и отрицательные значения). Пустое поле отображается с подсказкой `0` и при телепортации считается за `0`.
4. Соединяйте **«Телепорт»** с любыми узлами (`Реплика`, `Кнопка`, `Если`, `Случайный выбор`, `Таймер`, `Время`, `Урон`, `Радиус`, `Триггер`, другой `Телепорт`, карточки блока/двери/сундука). Узел выполняется мгновенно для игрока и передаёт управление следующему узлу по своему выходу.

## Безопасность и сохранение

- Переносит **только игрока** (`ServerPlayer`); НИП и мобы никогда не телепортируются этим узлом.
- Перед переносом сбрасывает `fallDistance`, огонь и скорость (`Vec3.ZERO`), сохраняя угол взгляда игрока.
- Неизвестные пользовательские измерения (`modid:dimension`), сохранённые в графе ранее, сохраняются в выпадающем списке без потери.
- Формат хранения внутри штатного графа: `type = TRIGGER (2)`, `special = 0`, `action = "trigger:teleport:<dimensionId>|<x>|<y>|<z>"`, поэтому работают отмена/повтор, копирование/вставка и сохранение схем через якоря (`Anchor420`).

## Изменённые и добавленные файлы

- `dev.settledlands.npc.TeleportNode424` — парсер, валидатор координат, таблица миров и константы.
- `dev.settledlands.npc.TeleportActions424` — серверное выполнение кросс-мерной телепортации игрока.
- `dev.settledlands.npc.client.TeleportCard424` — отрисовка карточки `220x100`, строки меню НИП и колбэков инспектора.
- `dev.settledlands.npc.client.BlockMenu363` + `Npc{BlockGraph351,DoorGraph382,ChestPalette396}Mixin` — пункт «+ Телепорт» в редакторах блока/двери/сундука без изменения `BlockTrigger351.PALETTE_ROWS`.
- `dev.settledlands.mixin.Teleport{Actions,Wiring,ContextMenu,GraphUi,Inspector}Mixin424` — выполнение, последовательная проводка, меню, карточка и инспектор.
