# Settled Lands — Сборка 428 (`0.8.0-build428-unique-dungeon`)

База: `settledlands-0.8.0-build427-procedural-dungeon.jar` (`0.8.0-build427-procedural-dungeon`), без новых миксинов.

## Что изменено в Build 428

1. **Уникальный данж и коридоры для каждого игрока и при каждом входе (`unique_dungeon_per_entry=true`)**
   - В `config/settledlands/dungeon.properties` добавлена и по умолчанию включена опция:
     ```properties
     unique_dungeon_per_entry=true
     ```
   - При каждом входе через узел графа **«Телепорт»** в мир `settledlands:hell_dungeon` («Адский данж»), когда координаты оставлены пустыми **или равны `0, 0, 0`**, а также при команде `/settledlands dungeon enter` (без `<id>`):
     - выделяется **новая свободная ячейка `512 × 512`** в сетке данжей (шаг 512 по X/Z);
     - формируется независимый сид из сида мира, индекса ячейки, **UUID игрока** и `System.nanoTime()`;
     - игроки не попадают в один и тот же уже пройденный коридор, а при повторном входе получают новую планировку лабиринта;
     - игрок телепортируется **на точку входа стартового зала** новой ячейки (а не в крышу или пустоту на `(0, 0, 0)`).

2. **Почему раньше отправляло на `(0, 0, 0)` / в один и тот же коридор**
   - Карточка узла «Телепорт» показывает `X: 0  Y: 0  Z: 0` по умолчанию; до Build 428 явные `0, 0, 0` отправляли игрока буквально в координаты `(0, 0, 0)`, а пустые поля всегда вели в общий инстанс `"default"` (где уже стоял ранее построенный коридор).
   - В старом мире без `.bp` файлов (или на Build 426) строилась только одиночная стартовая комната-коридор `start.slbp`.

3. **Кооператив, точные координаты и переключение режима**
   - `/settledlands dungeon enter <id>` — вход в уже созданный инстанс по его идентификатору (список инстансов и их координат показывает `/settledlands dungeon list`), чтобы войти с другом в один и тот же данж.
   - Узел «Телепорт» с **ненулевыми** координатами (например `516, -8, 4`) по-прежнему телепортирует точно в заданную точку.
   - Если нужен прежний общий данж `"default"` для всех, установите `unique_dungeon_per_entry=false` в `config/settledlands/dungeon.properties` и выполните `/settledlands dungeon reload`.

## Как посмотреть полный процедурный «Адский данж» в игре

1. Установите `settledlands-0.8.0-build428-unique-dungeon.jar` в `mods/`.
2. Скопируйте файлы `.bp` (например все файлы из архива `Данж.rar`, включая `старт.bp`) в одну из папок:
   - `config/settledlands/blueprints/` (в папке вашей сборки/сервера), **или**
   - `config/axiom/blueprints/` (папка Axiom по умолчанию — мод подхватывает её автоматически).
3. **Создайте новый мир** (если измерение `settledlands:hell_dungeon` не было в старом сохранении) или запустите существующий мир с уже загруженным измерением, затем выполните в чате:
   - `/settledlands dungeon reload` — перечитать папку `.bp`;
   - `/settledlands dungeon info` — убедиться, что измерение «готово», `уникальный/вход: true`, и видны загруженные комнаты (`комнат: 48` для `infernal`).
4. Активируйте узел **«Телепорт»** → `Адский данж` (или выполните `/settledlands dungeon enter`):
   - первые 8 комнат вокруг входа строятся мгновенно, остальные 60–80 комнат достраиваются по мере продвижения без фризов;
   - вернуться обратно в точку, откуда вы пришли, можно командой `/settledlands dungeon leave`.
