# Settled Lands 0.8.0 Build 441 — Полноэкранный редактор пулов, единое поле кол-ва, шанс по редкости (CS:GO), лимит веса ящика и тихий якорь узлов

База: `settledlands-0.8.0-build440-loot-pool-editor-gui.jar`

## Что исправлено и переработано

### 1. Список предметов в редакторе пула до самого низа экрана
- **`LootPoolEditorScreen440`**: снято искусственное ограничение высоты панели (`390` px) — окно редактора теперь разворачивается на всю доступную высоту экрана (`height - 16`, ширина до `700` px), а таблица записей тянется вплотную до нижних кнопок (`btnY - 6`).
- Убрана пустая постоянная нижняя полоса под таблицей: при обычном редактировании вся высота отдана строкам таблицы. Временная полоса предпросмотра (`Тест броска`) или статуса появляется снизу только при необходимости (и скрывается кликом, крестиком `[x]` или при дальнейшем редактировании), автоматически возвращая полный список до кнопок.
- **`LootPoolItemPickerScreen440`**: аналогично снято ограничение высоты каталога предметов (`height - 16`), чтобы при выборе предметов помещалось больше рядов иконок.

### 2. Объединённое поле количества предметов (`Кол-во`)
- В **`LootPoolEditorScreen440`** два отдельных поля **Мин / Макс** заменены на одно компактное текстовое поле **`Кол-во`** (ширина `52` px, подсказка `1-4`).
- Поддерживаются как одиночные значения (`1`, `16`), так и диапазоны через `-` (`2-6`). При сохранении инвертированные диапазоны вроде `6-2` автоматически нормализуются в `2-6`, а `1-1` — в `1`.
- В **`LootPool436.parseItemCountRange`** добавлена строгая проверка формата и границ `1..64` (неполный или некорректный ввод подсвечивается красной рамкой без потери текста).

### 3. Новая механика: `Редкость` задаёт процентный шанс выпада (как кейсы CS:GO), а `Вес` — ограничитель ящика
- **Редкость (`rarity`) — шанс выпадения предмета**:
  - При ролле предмета в **`LootPool436.rollDrops`** вероятность выпадения рассчитывается пропорционально значению **`Редк.`** (`rarity / sum(rarity)` среди подходящих предметов) — как в кейсах игр вроде CS:GO.
  - Поддерживаются как целые числа (`80`, `20`, `5`), так и дробные вероятности (`79.92`, `15.98`, `3.2`, `0.64`, `0.26`) — при чтении/сохранении `.txt` пулов, передаче по сети (`encodeEntriesWire` / `decodeEntriesWire`) и расчёте живой колонки **`Шанс`** в редакторе.
  - Для новых добавляемых предметов по умолчанию выставляются удобные значения `Редк. = 50`, `Вес = 10`.
- **Вес (`weight`) — вместимость ящика (сундука / мебели)**:
  - Значение **Вес ящика** в инспекторе узла (`rawWeight`, например `40` или диапазон `20-60`) задаёт суммарный лимит веса, который может вместить конкретный ящик.
  - Каждое выпадение предмета расходует `entry.weight` из оставшейся вместимости ящика: например, при весе ящика **`40`** в него поместится максимум **2 меча весом `20`** (`20 + 20 = 40`) или **4 книги весом `10`** (`10 × 4 = 40`). Предметы, не помещающиеся в остаток веса ящика, не могут выпасть в оставшиеся слоты.
  - Если поле **`Макс. шт.`** (`rolls`) в инспекторе узла оставить пустым при указанном **Весе ящика**, генерация заполняет ящик до исчерпания лимита веса (до `54` позиций). Если `Макс. шт.` указано явно (например `3`), срабатывает и лимит штук, и лимит веса (что закончится раньше).
  - Поле **Лимит редкости** на узле (`rawRarity`) оставлено опциональным фильтром верхней границы (пусто = без ограничений) для полной совместимости с существующими узлами графа и таблицами.
- Обновлены подсказки в инспекторе узла, карточке узла (`LootPoolCard436`), заголовках столбцов таблицы редактора (всплывающие tooltip-подсказки при наведении) и справке **`README_FORMAT.txt.disabled`** (`LootPoolManager436`).

### 4. Отключение звуков жителя у якоря узлов (`settledlands:guide_trigger`)
- **Причина**: `GuideTriggerNpc` (невидимый маркер-триггер, используемый в том числе якорем `NpcGraphAnchor420`) наследует `GuideNpc`, у которого `getAmbientSound()` / `getHurtSound(...)` / `getDeathSound()` возвращали звуки ванильного жителя (`SoundEvents.VILLAGER_AMBIENT` и др.), а прежний `GuideCorpseSilentMixin` заглушал только `GuideCorpseNpc`.
- **Решение**: добавлен общий миксин **`GuideTriggerSilentMixin441`** (зарегистрирован в `settledlands.mixins.json` -> `mixins`), который возвращает `null` из `getAmbientSound()`, `getHurtSound(DamageSource)`, `getDeathSound()` и `0.0F` из `getSoundVolume()` для всех сущностей `GuideTriggerNpc` — включая уже существующие якоря и триггеры в сохранённых мирах, схематиках и данжах.
