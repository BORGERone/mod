# Settled Lands 0.8.0 Build 447 — Модульный нодовый граф `trialtuner:trial_spawner`

База: `settledlands-0.8.0-build446-auto-cleanup-and-trial-spawner.jar`

## Что изменилось в Build 447

Монолитное модальное окно настроек центрального триал-спавнера заменено полноценной **модульной архитектурой на нодах прямо на холсте графа**, полностью совместимой с серверным движком Build 446 и старыми сохранениями.

### 1. Центральная нода-хаб `Триал-спавнер` (`256×176`, `TrialCard446`)
- **8 цветовых левых входных слотов** (`x = 0`, `y = 28..154` с шагом `18 px`) — по одному на каждый тип модуля конфигурации:
  1. `0` **Режим** (`#56D38C`) — обычный / зловещий, масштабирование от игроков;
  2. `1` **Радиус** (`#67B8FF`) — дальность активации и радиус спавна;
  3. `2` **Волна** (`#F5B841`) — базовое количество мобов, прирост за игрока, одновременных, размер пачки;
  4. `3` **Тайминги** (`#C084FC`) — мин/макс задержка спавна и перезарядка;
  5. `4` **Мобы** (`#FB7185`) — пул сущностей и их веса;
  6. `5` **Награды** (`#38BDF8`) — таблица наград, веса, min/max и шанс выпадения;
  7. `6` **Зловещий** (`#2DD4BF`) — множитель мобов, модификаторы брони/эффектов, опасности арены;
  8. `7` **Защита** (`#FB923C`) — запрет ломки блоков (радиус/секунды/сила эффекта) и самоуничтожение после N волн.
- **4 правых выходных пина** сохраняют прежнюю раскладку и логику: `Старт` (`y = 32`), `Зачистка` (`y = 50`), `Снос` (`y = 68`), `Игрок` (`y = 92`).
- В инспекторе хаба убрана кнопка `btn_configure`, добавлены статус подключения всех 8 слотов и кнопка **`Восстановить модули`** (`btn_restore_modules`) для переподключения отвязанных или создания недостающих модулей.

### 2. 8 специализированных модульных карточек (`TrialModule447`, `220×100`, `TrialModuleCard447`)
- Хранятся на нодах `NpcDialogueGraph.TRIGGER` со служебным префиксом `trigger:tmod:<slot>:` и собственным правым ромбовидным выходом (`220, 50`).
- **Первичное открытие графа** автоматически создаёт хаб на `(660, 247)` (`varOp = 1`) и все 8 подключённых модулей в шахматной двухколоночной раскладке слева (`x = 40` / `340`), центрируя камеру слева от инспектора (`TrialModuleUi447Mixin`).
- **Автомиграция Build 446 -> Build 447**: старый граф (`varOp == 0`) при открытии автоматически преобразует существующие настройки `hub.action` в 8 подключённых модульных карточек без потери данных.
- **Каскадная компиляция (`TrialModule447.compileConfig`)**: подключённые модули перезаписывают соответствующие поля эффективного `TrialConfig446` на `hub.action` (при каждом изменении, удалении узла и сохранении графа); при отключении или удалении модуля соответствующий блок автоматически откатывается к значениям по умолчанию. Поддерживается двусторонняя синхронизация с живым `TrialSpawnerBlockEntity` (`syncFromLiveSpawner`).
- **Интерактивные провода (`TrialModuleSocket447Mixin`)**:
  - перетаскивание цветной кривой Безье с правого ромба модуля на левый слот хаба (или в обратную сторону, строго по совпадению номера слота `0..7` либо перетаскиванием прямо на карточку хаба);
  - **ПКМ по пину** отвязывает модуль/слот; **СКМ по проводу** перерезает кабель;
  - стоковые провода между модулем и хабом скрываются при отрисовке `wires()`, чтобы не дублировать цветной кабель модулей.
- **Контекстное меню палитры (`BlockMenu363`, `NpcTrialPalette446Mixin`)**: при ПКМ по холсту редактора спавнера помимо общих триал-триггеров и ноды `Триал-спавнер` можно добавить любой из 8 модулей (при свободном слоте он сразу подключается к хабу).
- **Модальный пикер сущностей/предметов (`TrialModulePickerScreen447`)** для модулей `Мобы` и `Награды` + инспектор каждого модуля в боковой панели (`TrialModuleInspector447Mixin`) с полным списком параметров, прокруткой и кнопками привязки/отвязки/удаления.
- Кросс-графовый узел **`Триал-спавнер`** (`TrialControlNode446`, диалог `TrialControlConfigScreen446`) и система автоочистки (`BlockDestroy446Mixin`, `GraphBlockCleanup446`) полностью сохранены без изменений.
