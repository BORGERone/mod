# Settled Lands 0.8.0 Build 451 — Очистка 3D-каталога мобов и дополнительная нижняя строка

База: `settledlands-0.8.0-build450-universal-ranges-and-compact-mob-catalog.jar`

## Что изменилось в Build 451

Точечная доработка интерфейса экрана выбора моба (`TrialMobCatalogScreen449`) по замечаниям с реального экрана:

1. **Убраны лишние элементы заголовка, кнопка «Назад» и нижняя подсказка**
   - Сверху полностью убраны надпись `Выбор моба (N)` / `3D-каталог мобов (N)` и кнопка `Назад` (закрытие окна по-прежнему работает по выбору моба и клавише `Esc`).
   - Снизу полностью убрана постоянная полоса подсказки `Нажмите на карточку моба, чтобы поставить его в строку` (плашка статуса появляется только при действии с обратной связью — например, Shift+ЛКМ или неверный ID в `+ По ID`).

2. **Область карточек растянута вниз и вверх — внизу помещается ещё одна строка**
   - Строка поиска и кнопок фильтра поднята в самый верх панели (`topY = panelY + 5`, поля выровнены по единой внутренней ширине с сеткой и скроллбаром).
   - Начало области карточек смещено вверх с `panelY + 37` до **`panelY + 25`**, нижний отступ сокращён с `14` до **`4 px`**, панель расширена до `width - 6 × height - 6`.
   - Сетка отрисовки и фон контейнера теперь занимают всю растянутую высоту `gridH` целиком; введено число рисуемых строк `drawRows = ceil(gridH / (CELL_H + CELL_GAP))`, а `enableScissor` аккуратно обрезает нижнюю частичную строку по границе сетки. На том же разрешении, где раньше помещалось ровно 3 ряда, снизу отчётливо отображается **4-я строка** (и по её карточкам можно кликать напрямую).

3. **Подсказка в строке поиска больше не вылезает за пределы поля**
   - Текст `gui.settledlands.trial.mob_cat.search_hint` сокращён с `Поиск по имени, моду или ID (minecraft:breeze)...` до **`Поиск: имя, мод, ID`** (`Search: name, mod, ID` в `en_us.json`).
   - Дополнительно в `TrialMobCatalogScreen449#init` строка подсказки обрезается по реальной ширине поля (`TrialMobPreview449.clip(font, rawHint, Math.max(24, searchW - 10))`), поэтому физически не может перекрыть соседние кнопки на любом масштабе GUI.
