## Что изменено в Build 456

### 1. Нода «Мат выражение» и нода «Переменная» (без белых контактов)
- **Переименование нод (RU / EN)**:
  - Бывшая нода «Переменная» (`NpcDialogueGraph.VARIABLE`, тип `4`, операции `+`, `-`, `*`, `/`, `=`, `^`, `%`, `mod`, `min`/`max`, `|x|`, `-x`) переименована в **«Мат выражение»** (`Math Expression`) во всех графах, меню добавления (`+ Мат выражение`), описаниях, палитрах блоков и тултипах.
  - Бывшая нода «Значение переменной» (`VarDataNode453`, ранее также носившая марку `UE5`) переименована в **«Переменная»** (`Variable`) по всей русской и английской локализации.
- **У ноды «Переменная» убраны белые контакты выполнения**:
  - На карточке «Переменная» нет левого и правого белых портов (`hitPort` возвращает `-1`, меню создания больше не привязывает её белым проводом через `pendingWireFrom`, `connect` отвергает белые провода с/на эту ноду, а рантайм-исполнитель диалогов и блоков игнорирует белые обходы через неё).
  - По бокам карточки ровно по центру (`y = 50`) расположены только **оранжевый вход** (слева) и **оранжевый выход** (справа), а также **синий вход субъекта** внизу (`y = 92`).
- **Автономный приём и передача данных**:
  - **Приём с «Мат выражения» и цепочек**: «Переменная» сама принимает любые значения, переданные на её оранжевый вход (как от ноды «Мат выражение», так и по каскаду от другой «Переменной»), независимо от того, задано ли ей имя вручную (для безымянной ноды используется внутренняя память узла `__slvar_<id>` с сохранением области `Персональная` / `Общая` / `Локальная` и учётом её собственного синего пина субъекта).
  - **Отдача с оранжевого выхода**: отдаёт текущее записанное значение (включая `0`, если в ноду уже было записано `0`) во все подключённые далее «Мат выражение», `Условие If`, `Pursuit` или другие ноды «Переменная».

### 2. Переключатель формы зоны «Круг / Квадрат» для «В радиусе» и «Цель»
- **Режим «Квадрат» (Чебышёвский бокс, 3D куб)** добавлен в инспектор и на карточки нод **`В радиусе` (`CHECK`, тип 5)** и **`Цель` (`RADIUS`, тип 15)**:
  - По умолчанию сохраняется классический **«Круг»** (сфера `dx² + dy² + dz² ≤ r²`).
  - В режиме **«Квадрат»** проверка идёт по каждой оси независимо: `|dx| ≤ r && |dy| ≤ r && |dz| ≤ r` (включая точные грани и углы куба `[x ± r, y ± r, z ± r]`).
- **Охват всех путей проверки и визуализации**:
  - **NPC-диалоги, условия и радиусные вложения** (`GuideDialogue`: `checkProximityCondition`, `findCheckTarget`, `initiatorExecutesWithRadiusGate`, `expandRadiusAttachments`),
  - **Триггерные блоки / двери / сундуки / спавнеры** (`BlockTrigger351`, `NpcRadiusZone320`),
  - **Подсветка границ частицами** (`RadiusPass354`): в режиме **«Квадрат»** вместо кругового кольца рисуется контур квадратного/кубического периметра по 4 углам (от центра блока `+0.5` для блоков).
- **Интерфейс, сохранение и буфер обмена**:
  - Кнопка переключателя **«Форма зоны: Круг / Квадрат»** под строкой «Видимость» мгновенно сохраняет состояние на сервер (`save()`) для перерисовки частиц.
  - На карточке в правом верхнем углу отображается компактный бейдж (`○ Круг` / `□ Квадрат`) и подсказки в инспекторе (`GraphTooltips448`).
  - Флаг `SquareZone456` сохраняется в NBT-графе (`VarGraphIoMixin453`), при дублировании нод (`RadiusZoneNodeMixin456`) и в текстовом буфере обмена (`NpcGraphClipboard318`, попутно исправлено копирование/вставка нод `RADIUS` типа `15`).
