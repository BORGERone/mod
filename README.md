# No Man's Land — Dark Ages (NeoForge port)

Java-порт Bedrock-аддона **No Man's Land – Dark Ages 0.2** (автор: Hazelism) на **NeoForge 1.21.1**.
Оригинальные модели, анимации, текстуры и звуки переносятся 1:1, вся логика переписывается на Java 21.

## Текущее состояние: Этап 0 + вертикальный срез

- Каркас NeoForge 1.21.1 (ModDevGradle 2.0.91, NeoForge 21.1.176, Parchment 2024.11.17)
- GeckoLib 4.7.5.1 как обязательная зависимость — рендерит оригинальные Bedrock `.geo.json` / `.animation.json`
- 6 предметов + яйцо призыва Undead, творческая вкладка, 5 рецептов, EN/RU локализация
- Моб **Undead**: HP 40, урон 3, радиус чутья 20 (значения из оригинала), анимации idle/walk/run/attack/death, натуральный спавн в оверворлде

Подробный план по этапам — в [PORTING_PLAN.md](PORTING_PLAN.md).

## Сборка

Требуется **JDK 21** (именно 21, не 17 и не 25).

```bash
./gradlew build          # jar: build/libs/nomansland-0.1.0.jar
./gradlew runClient      # дев-запуск клиента
./gradlew runServer      # дев-запуск сервера (--nogui)
./gradlew runData        # датагенерация
```

Для игры: NeoForge 1.21.1 + **GeckoLib 4.7.5.1 (NeoForge)** в папке `mods` рядом с этим модом.

## Архитектура

```
com.hazelism.nomansland
├─ NoMansLand        — точка входа, регистрация, правила производительности
├─ NMLConfig         — серверный конфиг (лимиты спавна и т.д.)
├─ registry/         — DeferredRegister: предметы, сущности, вкладка
├─ entity/           — логика мобов (общий код, на сервер безопасно)
└─ client/           — ТОЛЬКО клиент: модели, рендереры. На сервере не загружается
```

## Правила оптимизации (обязательны для всех следующих этапов)

1. Никаких сканов мира и перебора сущностей в тиках — только реакции на события.
2. Никаких аллокаций (`new Vec3`, стримы, боксы) в `tick()`, анимационных предикатах и частицах.
3. Клиентские классы — только под `.client`, регистрация через `Dist.CLIENT`; выделенный сервер их не грузит.
4. Синхронизация состояния мобов — через `SynchedEntityData`, кастомные пакеты только где нет ванильного механизма.
5. Частицы — клиентские, с жёсткими капами в конфиге; сервер шлёт точечно, не broadcast.
6. ИИ — ванильный `PathNavigation` + Goal'и с интервалами перепроверки, никакого самописного A*.
