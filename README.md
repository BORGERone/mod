# ivy_oleander skins

| File | Description |
| --- | --- |
| `ivy_oleander.bbmodel` | оригинальная модель (не тронута) |
| `ivy_oleander_villager.bbmodel` | та же модель и все 82 анимации, но новая текстура — «селянин/крестьянин» |
| `ivy_oleander_villager.png` | отдельно текстура 128×128 для варианта «селянин» |
| `preview_villager.png` | сравнение: сверху оригинал, снизу новый скин, 5 ракурсов |

## Вариант «селянин» (`ivy_oleander_villager`)

Геометрия, кости, UV-разметка и анимации полностью совпадают с оригиналом —
перерисована только текстура:

* **рубаха из грубого льна** вместо чёрной куртки, с заплатой, боковыми швами и верёвочным поясом;
* **клетчатый платок на груди** (бывшая красная перевязь);
* **платок на голове** (бывшие рожки/хвостики остались прядями волос), открытое лицо с обычными глазами вместо красных;
* **грубые штаны с потёртостями и заплатой на колене**, тёмные сапоги с отворотом;
* **закатанные рукава** — открытые предплечья;
* **мешковина-заплечник**: швы, верёвочные лямки и солома, торчащая сверху;
* тёмные «нитки волос», которые в оригинале лежали поверх тела, убраны, чтобы не читались дырками.

### Перегенерация

```bash
pip install pillow numpy
python3 tools/make_villager_skin.py     # .bbmodel + .png
python3 tools/make_preview_sheet.py     # preview_villager.png
```

Палитры и раскладка «часть модели → цвет» задаются таблицами `TARGETS` / `THEMES`
в `tools/make_villager_skin.py`; лицо рисуется вручную в `FACE`/`draw_head()`,
мелкие детали — в `draw_details()`.
